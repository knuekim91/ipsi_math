## 문제

<p>최고차항의 계수가 1인 이차함수 <span class="m">f(x)</span>와 양수 <span class="m">k</span>가 다음 조건을 만족시킨다.</p>
<span class="cond m">(가) 모든 실수 a에 대하여 lim<sub>x→a</sub> (x−k)f(x) / (f(x) + f(x−t))의 값이 존재하도록 하는 양수 t의 집합은 {t | t ≥ 3}이다.</span>
<span class="cond m">(나) f(0) = 4</span>
<p><span class="m">f(6)</span>의 값을 구하시오.</p>

## 발상

같은 규칙을 <b>거꾸로</b> 쓴다. 중근이 큰 근이므로 <span class="m">α = k</span>이고 <span class="m">β = k − 3</span>. 즉 <span class="m">f</span>가 <span class="m">k</span> 하나로 표현되고, <span class="m">f(0) = 4</span>가 <span class="m">k</span>에 대한 이차방정식이 된다.

## 풀이

<p><span class="step">① f를 k로.</span> <span class="m">α = k, β = k−3</span>이므로</p>
<p class="m">f(x) = (x−k)(x−k+3)</p>

<p><span class="step">② 조건 (나).</span></p>
<p class="m">f(0) = (−k)(3−k) = k<sup>2</sup> − 3k = 4 → k<sup>2</sup> − 3k − 4 = 0 → (k−4)(k+1) = 0</p>

<p><span class="step">③ 부호 조건.</span> <span class="m">k</span>는 양수이므로 <span class="m">k = 4</span>. (<span class="m">k = −1</span>이면 <span class="m">f(6) = 70</span>이 되므로 이 조건이 답을 가른다.)</p>

<p class="m">f(x) = (x−4)(x−1) → f(6) = 2 × 5 = 10</p>

## 함정

<span class="m">k = −1</span>도 <span class="m">f(0) = 4</span>를 만족시킨다. <b>&lsquo;양수 k&rsquo;라는 한 단어가 근을 거르는 장치</b>다.

## 노하우

<b>같은 규칙이라도 &lsquo;t의 집합 → f&rsquo; 방향과 &lsquo;f → t의 집합&rsquo; 방향 양쪽으로 쓸 수 있어야 한다.</b> 기출은 대개 앞 방향이지만, 응용 문항은 뒤 방향으로 묻는다. 규칙을 <b>등식</b>(t₀ = α − β)으로 기억하면 어느 쪽으로든 풀린다.
