## 문제

<p>최고차항의 계수가 1인 이차함수 <span class="m">f(x)</span>가 다음 조건을 만족시킬 때, <span class="m">f(6)</span>의 값을 구하시오.</p>
<span class="cond m">모든 실수 a에 대하여 lim<sub>x→a</sub> (x−3)f(x) / (f(x) + f(x−t))의 값이 존재하도록 하는 양수 t의 집합은 {t | t ≥ 2}이다.</span>

## 발상

<b>f의 두 근을 α &gt; β 라 두는 순간 전부 결정된다.</b> 분모의 판별식이 0이 되는 경계는 <span class="m">t = α − β</span>이고, 그때 중근은 언제나 <b>큰 근 α</b>다. 따라서 분자의 나머지 인수 <span class="m">(x−3)</span>이 <span class="m">x = α</span>에서 0이어야 한다.

## 풀이

<p><span class="step">① 일반 규칙.</span> <span class="m">f(x) = (x−α)(x−β)</span>, <span class="m">α &gt; β</span>라 하면 <span class="m">D(x) = f(x)+f(x−t)</span>의 판별식은 <span class="m">4{(α−β)<sup>2</sup> − t<sup>2</sup>}</span>이므로 경계는 <span class="m">t<sub>0</sub> = α − β</span>, 그때의 중근은 <span class="m">x = α</span>.</p>

<p><span class="step">② 적용.</span> <span class="m">t<sub>0</sub> = 2 → α − β = 2</span>. 중근 <span class="m">α</span>에서 분자가 2중으로 0이어야 하는데 <span class="m">f(α)=0</span>은 이미 성립하므로 <span class="m">α − 3 = 0</span>, 즉 <span class="m">α = 3</span>.</p>

<p><span class="step">③ f 결정.</span> <span class="m">β = 1</span>이므로 <span class="m">f(x) = (x−3)(x−1) = x<sup>2</sup> − 4x + 3</span></p>

<p class="m">f(6) = 36 − 24 + 3 = 15</p>

## 함정

<span class="m">α = 3</span>이 <b>큰 근</b>이라는 것이 결정적이다. <span class="m">β = 3</span>으로 두면 <span class="m">α = 5</span>가 되어 중근이 5인데 분자는 5에서 0이 아니므로 <span class="m">t = 2</span>가 조건을 만족하지 못한다.

## 노하우

<b>f(x)+f(x−t) 꼴의 분모는 &lsquo;f를 t만큼 평행이동해 더한 것&rsquo;이고, 그 판별식이 0이 되는 순간은 정확히 t = (f의 두 근의 차)다.</b> 이 한 줄을 외워두면 이 유형은 판별식을 전개하지 않고도 풀린다.
