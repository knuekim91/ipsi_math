## 문제

<p>최고차항의 계수가 1인 이차함수 <span class="m">f(x)</span>가 다음 조건을 만족시킬 때, 가능한 모든 <span class="m">f(0)</span>의 값의 합을 구하시오.</p>
<span class="cond m">모든 실수 a에 대하여 lim<sub>x→a</sub> (x<sup>2</sup>−4)f(x) / (f(x) + f(x−t))의 값이 존재하도록 하는 양수 t의 집합은 {t | t ≥ 5/2}이다.</span>

## 발상

V1과 구조는 같지만 <b>분자의 나머지 인수가 <span class="m">(x−2)(x+2)</span>로 두 개</b>다. 큰 근 <span class="m">α</span>가 2일 수도, −2일 수도 있으므로 <b>두 경우를 모두 확인해야 한다.</b>

## 풀이

<p><span class="step">① 규칙.</span> <span class="m">t<sub>0</sub> = α − β = 5/2</span>, 중근은 큰 근 <span class="m">α</span>. 분자의 나머지 인수가 <span class="m">α</span>에서 0이어야 하므로 <span class="m">α = 2</span> 또는 <span class="m">α = −2</span>.</p>

<p><span class="step">② α = 2인 경우.</span> <span class="m">β = 2 − 5/2 = −1/2</span></p>
<p class="m">f(x) = (x−2)(x+½) → f(0) = −1</p>

<p><span class="step">③ α = −2인 경우.</span> <span class="m">β = −2 − 5/2 = −9/2</span></p>
<p class="m">f(x) = (x+2)(x+9/2) → f(0) = 9</p>

<p><span class="step">④ 두 경우 모두 t &lt; 5/2에서 조건이 깨지는지 확인.</span> 이때 분모는 서로 다른 두 실근을 갖고 그 둘이 모두 분자의 근이어야 하는데, 근의 합 <span class="m">t − b</span>를 분자의 근들의 합과 맞추면 양수 <span class="m">t</span>가 나오지 않는다. 두 경우 모두 적합.</p>

<p class="m">(−1) + 9 = 8</p>

## 함정

<span class="m">α = 2</span> 하나만 찾고 멈추기 쉽다. <b>분자의 인수가 여러 개면 중근 후보도 그 개수만큼</b> 생긴다는 것을 잊지 말 것.

## 노하우

<b>&lsquo;가능한 모든 값의 합&rsquo;이라는 발문은 경우가 둘 이상이라는 출제자의 예고다.</b> 하나를 찾았을 때 멈추지 말고 남은 후보를 끝까지 대입해 본다.
