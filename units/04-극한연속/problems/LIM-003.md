## 문제

<p>최고차항의 계수가 1인 이차함수 <span class="m">f(x)</span>가 다음 조건을 만족시킬 때 <span class="m">f(2)</span>의 값은?</p><span class="cond m">모든 실수 a에 대하여 lim<sub>x→a</sub> (2x+1)f(x) / (f(x) + f(x−t))의 값이 존재하도록 하는 양수 t의 집합은 {t | t ≥ 3/2}이다.</span><div class="choices"><span>① 5/2</span><span>② 5</span><span>③ 15/2</span><span>④ 10</span><span>⑤ 25/2</span></div>

## 발상

분모 D(x) = f(x)+f(x−t)는 이차식이다. <b>t가 커지면 판별식이 음수가 되어 극한이 자동으로 존재</b>하므로, t = 3/2 는 정확히 <b>판별식 = 0(중근)</b>인 경계다.

## 풀이

<p><span class="step">① 분모가 언제 문제를 일으키는지 본다.</span>
<span class="m">f(x) = x<sup>2</sup> + bx + c</span>로 두고
분모를 <span class="m">D(x) = f(x) + f(x−t)</span>라 하자.
분수의 극한은 <b>분모가 0이 되는 곳에서만</b> 존재하지 않을 수 있다.
그러니 <b>분모가 실근을 아예 갖지 않으면 모든 <span class="m">a</span>에서 극한이 존재</b>한다.</p>

<p><span class="step">② 분모를 정리하고 판별식을 구한다.</span></p>
<p class="m">f(x−t) = (x−t)<sup>2</sup> + b(x−t) + c = x<sup>2</sup> − 2tx + t<sup>2</sup> + bx − bt + c</p>
<p class="m">D(x) = 2x<sup>2</sup> + (2b − 2t)x + (t<sup>2</sup> − bt + 2c)</p>
<p>이차방정식 <span class="m">D(x) = 0</span>의 판별식을 계산하면</p>
<p class="m">(2b − 2t)<sup>2</sup> − 4 × 2 × (t<sup>2</sup> − bt + 2c) = 4(b<sup>2</sup> − 4c − t<sup>2</sup>)</p>

<p><span class="step">③ t가 커지면 저절로 극한이 존재함을 확인한다.</span>
판별식이 음수, 즉 <span class="m">t<sup>2</sup> &gt; b<sup>2</sup> − 4c</span>이면
분모가 0이 되는 실수가 없어 <b>모든 <span class="m">a</span>에서 극한이 존재</b>한다.
<span class="m">t</span>가 클수록 이 부등식은 잘 성립하므로,
조건을 만족시키는 <span class="m">t</span>의 집합이 <span class="m">{t | t ≥ 3/2}</span>라는 것은
<b><span class="m">t = 3/2</span>가 정확히 판별식이 0이 되는 경계</b>라는 뜻이다.</p>
<p class="m">b<sup>2</sup> − 4c = (3/2)<sup>2</sup> = 9/4</p>

<p><span class="step">④ 경계에서도 극한이 존재해야 한다.</span>
<span class="m">t = 3/2</span>일 때 분모는 <b>중근</b>을 갖는다. 그 중근을 <span class="m">r</span>이라 하면</p>
<p class="m">r = −(2b − 2t)/(2 × 2) = (t − b)/2</p>
<p>이 점에서도 극한이 존재하려면
<b>분자 <span class="m">(2x+1)f(x)</span>가 <span class="m">(x − r)<sup>2</sup></span>으로 나누어떨어져야</b> 한다.
가능한 경우는 두 가지다.</p>
<p>㉠ <span class="m">f(x)</span> 자체가 <span class="m">(x−r)<sup>2</sup></span>인 경우 —
그러면 <span class="m">f</span>가 중근을 가지므로 <span class="m">b<sup>2</sup> − 4c = 0</span>이 되어
③의 <span class="m">9/4</span>와 어긋난다. <b>불가능하다.</b></p>
<p>㉡ <span class="m">f(r) = 0</span>이면서 <span class="m">2r + 1 = 0</span>인 경우 —
이것만 남는다.</p>
<p class="m">2r + 1 = 0 → r = −1/2</p>

<p><span class="step">⑤ b와 c를 구한다.</span>
<span class="m">r = (t − b)/2</span>에 <span class="m">t = 3/2</span>, <span class="m">r = −1/2</span>를 넣는다.</p>
<p class="m">(3/2 − b)/2 = −1/2 → 3/2 − b = −1 → b = 5/2</p>
<p>③의 식에 넣어 <span class="m">c</span>를 구한다.</p>
<p class="m">b<sup>2</sup> − 4c = 9/4 → (5/2)<sup>2</sup> − 4c = 9/4 → 25/4 − 4c = 9/4 → 4c = 4 → c = 1</p>
<p class="m">f(x) = x<sup>2</sup> + (5/2)x + 1</p>
<p>(<span class="m">f(−1/2) = 1/4 − 5/4 + 1 = 0</span>이므로 ㉡의 조건도 실제로 만족한다.)</p>

<p><span class="step">⑥ t &lt; 3/2 에서는 정말 안 되는지 확인한다.</span>
그때는 판별식이 양수라 분모가 <b>서로 다른 두 실근</b>을 갖는다.
극한이 존재하려면 그 두 근이 모두 분자 <span class="m">(2x+1)f(x)</span>의 근이어야 하는데,
분자의 근은 <span class="m">−1/2</span>와 <span class="m">−2</span> 두 개뿐이다.
따라서 분모의 두 근이 <span class="m">−1/2</span>와 <span class="m">−2</span>여야 하고, 근과 계수의 관계로 합을 비교하면</p>
<p class="m">t − b = −1/2 + (−2) = −5/2 → t = b − 5/2 = 0</p>
<p><span class="m">t</span>는 양수여야 하므로 <b>모순</b>이다. 집합이 <span class="m">t ≥ 3/2</span>인 것이 맞다.</p>

<p><span class="step">⑦ 답.</span></p>
<p class="m">f(2) = 4 + 5 + 1 = 10</p>
<p class="m">답 ④</p>

## 다른 풀이

<p><span class="step">판별식을 전개하지 않는 길.</span> <span class="m">f</span>의 두 근을 <span class="m">α &gt; β</span>라 두고 <span class="m">f(x) = (x−α)(x−β)</span>로 쓰면, 분모 <span class="m">D(x) = f(x) + f(x−t)</span>에 대해</p>

<p class="m">판별식 = 0 ⟺ t = α − β, &nbsp; 그때의 중근은 x = α</p>

<p>가 항상 성립한다. (<span class="m">b<sup>2</sup>−4c = (α−β)<sup>2</sup></span>이고 중근은 <span class="m">(t−b)/2 = (α−β+α+β)/2 = α</span>이기 때문이다.)</p>

<p>이 규칙을 그대로 적용하면 이 문제는 세 줄이다.</p>
<p class="m">① t<sub>0</sub> = 3/2 → α − β = 3/2</p>
<p class="m">② 중근 α에서 분자가 2중으로 0 → f(α)=0은 이미 성립하므로 2α+1 = 0 → α = −1/2</p>
<p class="m">③ β = −2 → f(x) = (x+½)(x+2) → f(2) = 10</p>

<p><b>미지수 b, c를 아예 도입하지 않는다.</b> 이 규칙은 정방향(집합 → f)과 역방향(f → 집합) 양쪽으로 쓸 수 있다.</p>

## 노하우

<b>분수 극한의 존재 조건 = 분모가 0이 되는 곳에서 분자도 0, 그것도 분모가 겹친 만큼 겹쳐서 0.</b> 그리고 <b>문자로 된 상수의 범위가 부등식으로 주어지면 그 경계는 거의 항상 판별식 D = 0</b>이다.
