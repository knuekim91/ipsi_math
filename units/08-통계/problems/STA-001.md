## 문제

<p class="m">정규분포 N(1, σ<sup>2</sup>)을 따르는 확률변수 X에 대하여 P((3/2)σ ≤ X ≤ 2σ) = 0.044일 때, P(X ≥ 10/7)의 값을 표준정규분포표를 이용하여 구한 것은? (단, σ는 양수)</p><p class="m">[표] P(0≤Z≤0.5)=0.1915, P(0≤Z≤1.0)=0.3413, P(0≤Z≤1.5)=0.4332, P(0≤Z≤2.0)=0.4772, P(0≤Z≤2.5)=0.4938</p><div class="choices"><span>① 0.0062</span><span>② 0.0228</span><span>③ 0.0668</span><span>④ 0.1587</span><span>⑤ 0.3085</span></div>

## 발상

표준화하면 구간이 <span class='m'>[1.5 − 1/σ, 2 − 1/σ]</span>로 <b>길이가 항상 0.5</b>다. 그러니 <b>표에서 차가 0.044인 이웃 두 값</b>을 먼저 찾는다.

## 풀이

<p><span class="step">① 주어진 확률을 표준화한다.</span>
<span class="m">X</span>가 <span class="m">N(1, σ<sup>2</sup>)</span>을 따르므로
<span class="m">Z = (X − 1)/σ</span>로 두면 <span class="m">Z</span>는 표준정규분포를 따른다.
양 끝값을 각각 바꾼다.</p>
<p class="m">X = (3/2)σ → Z = ((3/2)σ − 1)/σ = 3/2 − 1/σ</p>
<p class="m">X = 2σ → Z = (2σ − 1)/σ = 2 − 1/σ</p>
<p>따라서 조건은 다음과 같다.</p>
<p class="m">P(3/2 − 1/σ ≤ Z ≤ 2 − 1/σ) = 0.044</p>

<p><span class="step">② 구간의 길이가 고정되어 있음을 본다.</span>
두 끝값의 차를 계산하면</p>
<p class="m">(2 − 1/σ) − (3/2 − 1/σ) = 1/2</p>
<p><b><span class="m">σ</span>가 무엇이든 구간의 길이는 항상 <span class="m">0.5</span></b>다.
그러니 표에서 <b>간격이 <span class="m">0.5</span>이면서 확률의 차가 <span class="m">0.044</span>인 두 지점</b>을 찾으면 된다.</p>

<p><span class="step">③ 표에서 거꾸로 찾는다.</span>
이웃한 값끼리 빼 본다.</p>
<p class="m">0.3413 − 0.1915 = 0.1498 &nbsp;/&nbsp; 0.4332 − 0.3413 = 0.0919</p>
<p class="m">0.4772 − 0.4332 = 0.0440 &nbsp;/&nbsp; 0.4938 − 0.4772 = 0.0166</p>
<p><span class="m">0.044</span>가 나오는 것은 <b><span class="m">z</span>가 <span class="m">1.5</span>에서 <span class="m">2.0</span>까지</b>인 구간이다.</p>

<p><span class="step">④ 구간이 오른쪽인지 왼쪽인지 정한다.</span>
표준정규분포는 <span class="m">0</span>에 대해 좌우대칭이므로
<span class="m">[1.5, 2.0]</span>과 <span class="m">[−2.0, −1.5]</span> 둘 다 확률이 <span class="m">0.044</span>다.
<b>여기서 <span class="m">σ &gt; 0</span>이 결정을 내려 준다.</b>
<span class="m">1/σ &gt; 0</span>이므로 왼쪽 끝값은</p>
<p class="m">3/2 − 1/σ &lt; 3/2</p>
<p>즉 <span class="m">1.5</span>보다 반드시 작다. 그러므로 구간은 <b>음의 쪽</b>이어야 한다.</p>
<p class="m">3/2 − 1/σ = −2</p>

<p><span class="step">⑤ σ를 구한다.</span></p>
<p class="m">1/σ = 3/2 + 2 = 7/2 → σ = 2/7</p>

<p><span class="step">⑥ 구하는 확률을 계산한다.</span>
<span class="m">X = 10/7</span>을 표준화한다.</p>
<p class="m">Z = (10/7 − 1) ÷ (2/7) = (3/7) × (7/2) = 3/2</p>
<p class="m">P(X ≥ 10/7) = P(Z ≥ 1.5) = 0.5 − P(0 ≤ Z ≤ 1.5) = 0.5 − 0.4332 = 0.0668</p>
<p class="m">답 ③</p>

## 함정

<span class='m'>1/σ = 0</span>도 수치상 0.044를 만들지만 σ가 존재하지 않는다. 정규분포에서 <b>표 값이 같은 구간은 항상 좌우 두 개</b>다.

## 노하우

<b>미지수가 σ에 들어 있으면 표준화 후 &lsquo;구간의 길이&rsquo;를 먼저 본다.</b> 길이가 고정이면 표에서 차를 맞추는 문제로 바뀌고, 남는 일은 부호를 정하는 것뿐이다.
