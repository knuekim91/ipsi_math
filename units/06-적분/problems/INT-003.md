## 문제

<p class="m">다항함수 f(x)가 모든 실수 x에 대하여 ∫<sub>−1</sub><sup>x</sup> f(t) dt = x f(x) − 2x<sup>3</sup> − 3x<sup>2</sup> + 6을 만족시킬 때, f(0)의 값은?</p><div class="choices"><span>① 6</span><span>② 7</span><span>③ 8</span><span>④ 9</span><span>⑤ 10</span></div>

## 발상

적분방정식에 쓸 수 있는 동작은 두 개뿐이다 — <b>아래끝 대입</b>과 <b>양변 미분</b>. 이 문제는 둘 다 쓴다.

## 풀이

<p><span class="step">① 적분방정식에 쓸 수 있는 두 가지 동작을 떠올린다.</span>
적분 기호가 들어 있는 등식에서 할 수 있는 일은 사실상 두 개뿐이다.
<b>㉠ 양변을 미분한다</b>(적분 기호가 사라진다),
<b>㉡ 적분이 0이 되는 값을 대입한다</b>(항이 하나 지워진다).
이 문제는 <b>둘 다</b> 필요하다.</p>

<p><span class="step">② 양변을 x로 미분한다.</span>
왼쪽은 미적분의 기본정리에 따라
<span class="m">∫<sub>−1</sub><sup>x</sup>f(t)dt</span>를 미분하면 <span class="m">f(x)</span>가 된다.
오른쪽의 <span class="m">xf(x)</span>는 <b>곱이므로 곱의 미분법</b>을 쓴다.</p>
<p class="m">f(x) = 1 × f(x) + x × f′(x) − 6x<sup>2</sup> − 6x</p>
<p>양변에서 <span class="m">f(x)</span>를 빼면 <b>왼쪽이 0이 된다.</b></p>
<p class="m">0 = xf′(x) − 6x<sup>2</sup> − 6x</p>
<p><span class="m">6x<sup>2</sup> + 6x</span>를 왼쪽으로 넘긴다.</p>
<p class="m">xf′(x) = 6x<sup>2</sup> + 6x</p>
<p>오른쪽을 <span class="m">x</span>로 묶는다.</p>
<p class="m">xf′(x) = x(6x + 6)</p>
<p><span class="m">f</span>가 다항함수라 <span class="m">f′</span>도 다항함수이므로,
<span class="m">x ≠ 0</span>에서 양변을 <span class="m">x</span>로 나눈 식이 <b>모든 <span class="m">x</span>에서 성립</b>한다.</p>
<p class="m">f′(x) = 6x + 6</p>

<p><span class="step">③ 적분해서 f를 구한다.</span>
적분상수를 <span class="m">C</span>라 하자.</p>
<p class="m">f(x) = 3x<sup>2</sup> + 6x + C</p>

<p><span class="step">④ x = −1을 대입해 C를 정한다.</span>
<b>적분의 아래끝이 <span class="m">−1</span>이므로 <span class="m">x = −1</span>을 넣으면 왼쪽 적분이 0</b>이 된다.
이것이 상수를 잡는 열쇠다.</p>
<p class="m">0 = (−1) × f(−1) − 2 × (−1)<sup>3</sup> − 3 × (−1)<sup>2</sup> + 6</p>
<p class="m">0 = −f(−1) + 2 − 3 + 6 = −f(−1) + 5</p>
<p class="m">f(−1) = 5</p>

<p><span class="step">⑤ ③의 식에 x = −1을 넣어 C를 구한다.</span></p>
<p class="m">f(−1) = 3 × 1 + 6 × (−1) + C = 3 − 6 + C = C − 3</p>
<p class="m">C − 3 = 5 → C = 8</p>

<p><span class="step">⑥ 구하는 값.</span>
<span class="m">f(x) = 3x<sup>2</sup> + 6x + 8</span>이므로</p>
<p class="m">f(0) = 8</p>
<p class="m">답 ③</p>

## 노하우

<b>∫<sub>a</sub><sup>x</sup> 꼴이 보이면 반사적으로 두 줄을 쓴다: &lsquo;x = a 대입&rsquo;과 &lsquo;양변 미분&rsquo;.</b> 미분은 함수의 형태를, 대입은 상수를 준다.
