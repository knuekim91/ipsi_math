## 문제

<p>최고차항의 계수가 6인 이차함수 <span class="m">f(x)</span>가 <span class="m">f(0) = 0</span>, <span class="m">∫<sub>0</sub><sup>2</sup> f(x) dx = 4</span>를 만족시킨다. &lt;보기&gt;에서 옳은 것만을 있는 대로 고른 것은?</p><span class="cond m">ㄱ. ∫<sub>0</sub><sup>2</sup> |f(x)| dx = 6</span><span class="cond m">ㄴ. g(1) = 0인 일차함수 g(x)에 대하여 ∫<sub>0</sub><sup>2</sup> (f(x)+g(x)) dx = 4이다.</span><span class="cond m">ㄷ. k &gt; 6인 각각의 실수 k에 대하여, ∫<sub>0</sub><sup>2</sup>(f(x)+h(x))dx = 4와 ∫<sub>0</sub><sup>2</sup>|f(x)+h(x)|dx = k를 동시에 만족시키는 일차함수 h(x)가 존재한다.</span><div class="choices"><span>① ㄱ</span><span>② ㄱ, ㄴ</span><span>③ ㄱ, ㄷ</span><span>④ ㄴ, ㄷ</span><span>⑤ ㄱ, ㄴ, ㄷ</span></div>

## 발상

f를 먼저 확정하고, ㄴ은 <b>x=1에 대한 대칭으로 적분이 0</b>임을 보고, ㄷ은 값을 만들지 말고 <b>연속성 + 중간값</b>으로 처리한다.

## 풀이

<p><span class="step">① 먼저 f를 완전히 결정한다.</span>
최고차항의 계수가 <span class="m">6</span>인 이차함수이고 <span class="m">f(0) = 0</span>이므로
상수항이 없다. 따라서 <span class="m">f(x) = 6x<sup>2</sup> + bx</span> 꼴이다.
남은 조건 <span class="m">∫<sub>0</sub><sup>2</sup>f(x)dx = 4</span>로 <span class="m">b</span>를 정한다.</p>
<p class="m">∫<sub>0</sub><sup>2</sup>(6x<sup>2</sup> + bx)dx = [2x<sup>3</sup> + bx<sup>2</sup>/2]<sub>0</sub><sup>2</sup> = 16 + 2b</p>
<p class="m">16 + 2b = 4 → 2b = −12 → b = −6</p>
<p class="m">f(x) = 6x<sup>2</sup> − 6x = 6x(x − 1)</p>
<p><b>근이 <span class="m">0</span>과 <span class="m">1</span></b>이라는 것을 기억해 둔다.</p>

<p><span class="step">② ㄱ을 확인한다.</span>
<span class="m">f(x) = 6x(x−1)</span>은 <span class="m">0 &lt; x &lt; 1</span>에서 음수,
<span class="m">1 &lt; x &lt; 2</span>에서 양수다.
<b>절댓값 적분은 부호가 바뀌는 <span class="m">x = 1</span>에서 구간을 끊어</b> 계산한다.</p>
<p class="m">∫f(x)dx = 2x<sup>3</sup> − 3x<sup>2</sup></p>
<p class="m">∫<sub>0</sub><sup>1</sup>f = (2 − 3) − 0 = −1 &nbsp; → &nbsp; 음수이므로 |·| = 1</p>
<p class="m">∫<sub>1</sub><sup>2</sup>f = (16 − 12) − (2 − 3) = 4 + 1 = 5</p>
<p class="m">∫<sub>0</sub><sup>2</sup>|f(x)|dx = 1 + 5 = 6 &nbsp; → &nbsp; <b>ㄱ은 참</b></p>

<p><span class="step">③ ㄴ을 확인한다.</span>
<span class="m">g</span>는 일차함수이고 <span class="m">g(1) = 0</span>이므로
<span class="m">x = 1</span>을 근으로 갖는다. 따라서 어떤 상수 <span class="m">m</span>에 대해</p>
<p class="m">g(x) = m(x − 1)</p>
<p>적분 구간 <span class="m">[0, 2]</span>는 <b><span class="m">x = 1</span>을 한가운데에 둔 구간</b>이고,
<span class="m">g</span>는 그 점을 지나는 직선이므로 왼쪽의 음수 넓이와 오른쪽의 양수 넓이가 정확히 상쇄된다.
실제로 계산해도 같다.</p>
<p class="m">∫<sub>0</sub><sup>2</sup>m(x−1)dx = m[(x−1)<sup>2</sup>/2]<sub>0</sub><sup>2</sup> = m(1/2 − 1/2) = 0</p>
<p>따라서 <span class="m">f</span>에 <span class="m">g</span>를 더해도 적분값이 변하지 않는다.</p>
<p class="m">∫<sub>0</sub><sup>2</sup>(f + g)dx = 4 + 0 = 4 &nbsp; → &nbsp; <b>ㄴ은 참</b></p>

<p><span class="step">④ ㄷ에서 h의 꼴부터 알아낸다.</span>
첫 번째 조건 <span class="m">∫<sub>0</sub><sup>2</sup>(f + h)dx = 4</span>는
<span class="m">∫<sub>0</sub><sup>2</sup>f = 4</span>이므로
<span class="m">∫<sub>0</sub><sup>2</sup>h dx = 0</span>을 뜻한다.
③에서 본 대로 일차함수의 적분이 <span class="m">[0,2]</span>에서 0이 되려면
<b><span class="m">h(1) = 0</span></b>이어야 한다. 그러므로</p>
<p class="m">h(x) = p(x − 1)</p>
<p class="m">f(x) + h(x) = 6x(x−1) + p(x−1) = (x − 1)(6x + p)</p>

<p><span class="step">⑤ 두 번째 조건의 값을 p로 나타낸다.</span>
<span class="m">p ≥ 0</span>으로 두면 다른 근 <span class="m">−p/6</span>이 <span class="m">0</span> 이하라
구간 <span class="m">[0,2]</span> 안에서 부호가 바뀌는 곳은 <span class="m">x = 1</span> 하나뿐이다.
그러면 절댓값 적분을 직접 계산할 수 있다.</p>
<p class="m">∫(x−1)(6x+p)dx = 2x<sup>3</sup> + (p−6)x<sup>2</sup>/2 − px</p>
<p class="m">∫<sub>0</sub><sup>1</sup> = −1 − p/2 &nbsp; → &nbsp; |·| = 1 + p/2</p>
<p class="m">∫<sub>1</sub><sup>2</sup> = 5 + p/2</p>
<p class="m">∫<sub>0</sub><sup>2</sup>|f + h|dx = (1 + p/2) + (5 + p/2) = 6 + p</p>

<p><span class="step">⑥ ㄷ을 판정한다.</span>
<span class="m">k &gt; 6</span>인 <span class="m">k</span>가 어떤 값으로 주어지든
<b><span class="m">p = k − 6</span></b>으로 두면 <span class="m">p &gt; 0</span>이고
위 식의 값이 정확히 <span class="m">k</span>가 된다.
그때 <span class="m">h(x) = (k−6)(x−1)</span>이 실제로 두 조건을 모두 만족시킨다.
<b>존재한다는 것을 실물로 보였으므로 ㄷ은 참</b>이다.</p>
<p>따라서 옳은 것은 <b>ㄱ, ㄴ, ㄷ</b>.</p>
<p class="m">답 ⑤</p>

## 다른 풀이

<p><span class="step">ㄷ을 중간값 정리 없이, 답을 직접 만들어서.</span> <span class="m">h(x) = p(x−1)</span>이고 <span class="m">f + h = (x−1)(6x+p)</span>인 것까지는 같다. 여기서 <b><span class="m">p ≥ 0</span>으로 한정</b>하면 다른 근 <span class="m">−p/6</span>이 구간 <span class="m">[0,2]</span> 밖에 있으므로, 부호가 바뀌는 곳은 <span class="m">x = 1</span> 하나뿐이다. 그러면 절댓값 적분이 손으로 계산된다.</p>

<p class="m">∫(x−1)(6x+p)dx = 2x<sup>3</sup> + (p−6)x<sup>2</sup>/2 − px</p>
<p class="m">∫<sub>0</sub><sup>1</sup> = −1 − p/2, &nbsp; ∫<sub>1</sub><sup>2</sup> = 5 + p/2</p>
<p class="m">F(p) = (1 + p/2) + (5 + p/2) = <b>6 + p</b></p>

<p>따라서 <span class="m">k &gt; 6</span>인 어떤 <span class="m">k</span>가 주어져도 <b><span class="m">p = k − 6</span></b>으로 두면 되고, 그때 <span class="m">h(x) = (k−6)(x−1)</span>이 실제로 조건을 만족시킨다.</p>

<p><b>"존재한다"를 존재성 정리가 아니라 실물로 답한 것</b>이라 훨씬 안전하다. 중간값 정리는 F가 연속임을 따로 말해야 하지만, 이 방법은 식 하나로 끝나고 <span class="m">k</span>와 <span class="m">p</span>의 관계까지 보여준다.</p>

## 함정

<span class='m'>p = −6</span>이면 <span class='m'>f+h = 6(x−1)<sup>2</sup></span>로 부호가 바뀌지 않아 F = 4가 최소. &lsquo;부호가 안 바뀌는 순간&rsquo;이 절댓값 적분의 극단값이다.

## 노하우

<b>① 절댓값 적분은 부호가 안 바뀌는 경우를 먼저 찾는다(= 최솟값). ② 대칭 구간에서 대칭점을 지나는 일차함수의 적분은 0. ③ &lsquo;모든 k에 대해 존재하는가&rsquo;는 연속성 + 중간값으로 답한다.</b>
