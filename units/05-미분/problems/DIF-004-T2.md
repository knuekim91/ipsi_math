## 문제

<p>두 함수 <span class="m">u(x) = 5|x−1|</span>, <span class="m">v(x) = −3|x−1|</span>에 대하여 <span class="m">h(x) = u(x) + v(x)</span>라 하자. <span class="m">x = 1</span>에서 <span class="m">h</span>의 뛰기(오른쪽 기울기 − 왼쪽 기울기)를 구하시오.</p>

## 발상

<b>세 함수의 뛰기를 각각 구해 나란히 놓아 본다.</b> <span class="m">u</span>와 <span class="m">v</span>의 뛰기를 더한 값이 <span class="m">h</span>의 뛰기와 같은지 눈으로 확인하는 것이 이 문제의 목적이다.

## 풀이

<p><span class="step">① u의 뛰기.</span> <span class="m">x ≥ 1</span>이면 <span class="m">u = 5(x−1)</span> 기울기 <span class="m">5</span>, <span class="m">x &lt; 1</span>이면 <span class="m">u = −5(x−1)</span> 기울기 <span class="m">−5</span>.</p>
<p class="m">뛰기(u) = 5 − (−5) = 10</p>

<p><span class="step">② v의 뛰기.</span> 같은 방법으로 오른쪽 <span class="m">−3</span>, 왼쪽 <span class="m">3</span>.</p>
<p class="m">뛰기(v) = −3 − 3 = −6</p>

<p><span class="step">③ h를 직접.</span> <span class="m">h = 5|x−1| − 3|x−1| = 2|x−1|</span>이므로 오른쪽 <span class="m">2</span>, 왼쪽 <span class="m">−2</span>.</p>
<p class="m">뛰기(h) = 2 − (−2) = 4</p>

<p><span class="step">④ 확인.</span></p>
<p class="m">뛰기(u) + 뛰기(v) = 10 + (−6) = 4 = 뛰기(h)</p>

<p><b>더한 함수의 뛰기는 각 뛰기의 합</b>이다. 당연한 이유가 있다 — <span class="m">h</span>의 왼쪽 기울기는 <span class="m">u</span>의 왼쪽 기울기와 <span class="m">v</span>의 왼쪽 기울기를 더한 것이고, 오른쪽도 마찬가지다. 그러니 그 차이인 뛰기도 더해진다.</p>

## 노하우

<b>왼쪽끼리 더하고 오른쪽끼리 더한다 → 뛰기도 더해진다.</b>
이것이 &lsquo;뛰기의 합&rsquo;이라는 말이 성립하는 근거다.
꺾이는 조각이 여러 개여도 <b>각각의 뛰기를 부호까지 살려 더하기만 하면</b> 전체의 뛰기가 나온다.
