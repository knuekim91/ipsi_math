## 문제

<p>함수 <span class="m">f(x)</span>를</p>
<span class="cond m">f(x) = 2x + a (x &lt; 1), &nbsp; f(x) = 2x + 5 (x ≥ 1)</span>
<p>이라 하자. <span class="m">f(x)</span>가 <span class="m">x = 1</span>에서 미분가능할 때, 상수 <span class="m">a</span>의 값을 구하시오.</p>

## 발상

<b>양쪽 다 기울기가 2로 이미 같다.</b> 그런데도 답이 정해진다는 것은, <b>기울기 말고 다른 조건이 하나 더 있다</b>는 뜻이다. 그것이 연속이다.

## 풀이

<p><span class="step">① 기울기는 이미 같다.</span> 왼쪽 <span class="m">2</span>, 오른쪽 <span class="m">2</span> → 뛰기 <span class="m">= 0</span>.</p>

<p><span class="step">② 그런데도 조건이 남는다.</span> <span class="m">a ≠ 5</span>이면 <span class="m">x = 1</span>에서 값이 <b>뚝 끊긴다.</b> 끊어진 자리에서는 애초에 접선을 그을 수 없으므로 미분가능이 아니다.</p>

<p><span class="step">③ 연속 조건.</span></p>
<p class="m">2(1) + a = 2(1) + 5 → a = 5</p>

<p>실제로 <span class="m">a ≠ 5</span>일 때 <span class="m">x = 1</span> 좌우의 평균변화율을 재어 보면 <b>값이 한없이 커진다.</b> 끊어진 높이를 아주 짧은 거리로 나누기 때문이다. "기울기가 2"라는 말이 그 점에서는 통하지 않는다.</p>

## 함정

<b>&lsquo;뛰기 = 0&rsquo;만 확인하고 끝내면 이 문제를 틀린다.</b> 뛰기는 <b>연속이라는 전제 아래에서</b> 쓰는 도구다. 다행히 우리가 다루는 문항들에서는 <span class="m">g</span>도 절댓값 함수도 <b>이어져 있는 것이 미리 보장</b>되어 있어 기울기만 따지면 된다 — 그 사실을 확인하고 넘어가는 것과 모르고 지나가는 것은 다르다.

## 노하우

<b>순서는 언제나 ① 연속인가 → ② 뛰기가 0인가 이다.</b>
문제에서 두 조각이 경계에서 같은 값을 갖는 것이 이미 보장되어 있으면 ①은 건너뛰어도 되지만,
<b>보장되어 있는지를 한 번은 확인</b>해야 한다.
