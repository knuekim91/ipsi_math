## 문제

<p><span class="m">P(x) = (x−1)(x−2)<sup>2</sup></span>에 대하여 함수 <span class="m">y = |P(x)|</span>가 미분가능하지 않은 점에서, 오른쪽 기울기와 왼쪽 기울기의 차(큰 것에서 작은 것을 뺀 값)를 구하시오.</p>

## 발상

절댓값은 <b>음수를 만나면 위로 뒤집는다.</b> 그러니 <b>부호가 바뀌는 곳에서만 꺾인다.</b> <span class="m">(x−2)<sup>2</sup></span>처럼 <b>제곱으로 붙은 근에서는 부호가 안 바뀌므로</b> 뒤집을 일이 없다.

## 풀이

<p><span class="step">① 부호를 살핀다.</span> <span class="m">(x−2)<sup>2</sup></span>은 항상 0 이상이므로 <span class="m">P</span>의 부호는 <span class="m">(x−1)</span>이 정한다.</p>
<p class="m">x &lt; 1 : P &lt; 0 &nbsp;/&nbsp; x &gt; 1 : P &gt; 0</p>
<p><span class="m">x = 2</span> 근처에서는 양쪽 다 <span class="m">P ≥ 0</span>이라 <b>부호가 안 바뀐다 → 꺾이지 않는다.</b></p>

<p><span class="step">② 꺾이는 곳은 x = 1 하나.</span> 그 점에서 <span class="m">P</span>의 기울기를 구하면</p>
<p class="m">P′(x) = (x−2)<sup>2</sup> + (x−1)·2(x−2) → P′(1) = 1</p>

<p><span class="step">③ 뒤집힌 쪽의 기울기.</span> <span class="m">x &lt; 1</span>에서는 <span class="m">|P| = −P</span>이므로 기울기가 <span class="m">−1</span>, <span class="m">x &gt; 1</span>에서는 <span class="m">|P| = P</span>이므로 <span class="m">1</span>.</p>
<p class="m">차 = 1 − (−1) = 2</p>

<p>일반적으로 <b>절댓값의 뛰기는 그 점에서의 기울기의 크기의 2배</b>다.</p>
<p class="m">뛰기 = 2|P′(그 점)|</p>

## 함정

<span class="m">x = 2</span>도 <span class="m">P</span>의 근이라서 꺾일 것 같지만 <b>아니다.</b> 근이라고 다 꺾이는 게 아니라 <b>부호가 바뀌는 근(홀수 번 겹친 근)</b>에서만 꺾인다. 제곱으로 붙은 근은 스치듯 닿았다 다시 올라가므로 뒤집을 것이 없다.

## 노하우

<b>절댓값 함수를 만나면 근을 나열하고 &lsquo;여기서 부호가 바뀌는가&rsquo;만 묻는다.</b>
바뀌면 꺾이고 뛰기는 <span class="m">2 × (기울기의 크기)</span>, 안 바뀌면 매끄럽다.
원문항에서 <span class="m">|(x−1)(x−a)(x−4+a)|</span>의 근 셋 중 <b>둘이 겹쳐야</b> 꺾이는 점이 하나로 줄어드는 이유가 이것이다.
