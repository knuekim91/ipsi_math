## 문제

<p>함수 <span class="m">g(x)</span>를</p>
<span class="cond m">g(x) = 10(x−1) (x &lt; 1), &nbsp; g(x) = −2(x−1) (x ≥ 1)</span>
<p>이라 하자. 양수 <span class="m">t</span>에 대하여 함수 <span class="m">h(x) = g(x) + t|x−1|</span>가 <span class="m">x = 1</span>에서 미분가능할 때, <span class="m">t</span>의 값을 구하시오.</p>

## 발상

1단에서 <b>미분가능 = 뛰기 0</b>, 2단에서 <b>뛰기는 더해진다</b>를 얻었다. 두 개를 이어 붙이면</p>
<p class="m">뛰기(g) + 뛰기(t|x−1|) = 0</p>
<p>이라는 <b>방정식 한 개</b>가 나온다. 이제 미지수를 구하는 계산일 뿐이다.

## 풀이

<p><span class="step">① g의 뛰기.</span> 왼쪽 기울기 <span class="m">10</span>, 오른쪽 기울기 <span class="m">−2</span>.</p>
<p class="m">뛰기(g) = −2 − 10 = −12</p>
<p>(<span class="m">x=1</span>에서 양쪽 모두 값이 0이라 <b>연속은 이미 만족</b>한다. 그래서 기울기만 보면 된다.)</p>

<p><span class="step">② 절댓값의 뛰기.</span> <span class="m">t &gt; 0</span>이므로 <span class="m">t|x−1|</span>의 왼쪽 기울기 <span class="m">−t</span>, 오른쪽 <span class="m">t</span>.</p>
<p class="m">뛰기 = t − (−t) = 2t</p>

<p><span class="step">③ 합을 0으로.</span></p>
<p class="m">−12 + 2t = 0 → t = 6</p>

<p><span class="step">④ 확인.</span> <span class="m">t = 6</span>이면 왼쪽 기울기 <span class="m">10 + (−6) = 4</span>, 오른쪽 <span class="m">−2 + 6 = 4</span>. 같으므로 꺾이지 않는다.</p>

## 노하우

<b>&lsquo;뛰기의 합 = 0&rsquo;은 새로운 규칙이 아니라 1단과 2단을 이어 붙인 것이다.</b>
① 미분가능은 뛰기가 0이라는 뜻이고(1단), ② 뛰기는 더해지므로(2단),
여러 조각으로 이루어진 함수는 <b>각 조각의 뛰기를 더해 0으로 놓으면</b> 된다.
<b>부호를 살려서 더하는 것</b>이 핵심이다 — 하나가 음수, 하나가 양수여야 지워진다.
