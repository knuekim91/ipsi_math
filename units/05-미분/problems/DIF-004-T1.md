## 문제

<p>함수 <span class="m">f(x)</span>를</p>
<span class="cond m">f(x) = ax + b (x &lt; 1), &nbsp; f(x) = 4x<sup>2</sup> (x ≥ 1)</span>
<p>이라 하자. <span class="m">f(x)</span>가 <span class="m">x = 1</span>에서 미분가능할 때, <span class="m">a − b</span>의 값을 구하시오.</p>

## 발상

<b>미분가능이라는 말에는 조건이 <u>두 개</u> 들어 있다.</b> ① 끊어지지 않았을 것(연속), ② 좌우 기울기가 같을 것. 조건이 둘이니 미지수도 둘을 정할 수 있다.

## 풀이

<p><span class="step">① 기울기를 맞춘다.</span> 왼쪽은 직선이라 기울기 <span class="m">a</span>. 오른쪽 <span class="m">4x<sup>2</sup></span>의 <span class="m">x=1</span>에서의 기울기는 <span class="m">8x</span>에 1을 넣어 <span class="m">8</span>.</p>
<p class="m">a = 8</p>

<p><span class="step">② 끊어지지 않게 한다.</span> 양쪽 값이 <span class="m">x = 1</span>에서 같아야 한다.</p>
<p class="m">a + b = 4 → 8 + b = 4 → b = −4</p>

<p><span class="step">③</span> <span class="m">a − b = 8 − (−4) = 12</span></p>

## 함정

기울기만 맞추고 끝내면 <span class="m">b</span>를 못 정하고, 연속만 맞추면 <span class="m">a</span>를 못 정한다. <b>두 조건을 모두 써야 답이 하나로 정해진다.</b>

## 노하우

<b>미분가능 = 연속 + (왼쪽 기울기 = 오른쪽 기울기).</b>
여기서 두 번째 조건을 <b>&lsquo;뛰기 = 0&rsquo;</b>이라고 바꿔 부르는 것뿐이다.
<span class="m">뛰기 = (오른쪽 기울기) − (왼쪽 기울기)</span>이므로, 뛰기가 0이라는 말과 두 기울기가 같다는 말은 <b>완전히 같은 말</b>이다.
