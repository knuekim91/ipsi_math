## 문제

<p>함수 <span class="m">f(x) = 3x</span>에 대하여 함수 <span class="m">g(x)</span>를 다음과 같이 정한다.</p>
<span class="cond m">g(x) = −f(x) (f(x) ≥ 0), &nbsp; g(x) = 7f(x) (f(x) &lt; 0)</span>
<p><span class="m">x = 0</span>에서 <span class="m">g</span>의 왼쪽 기울기와 오른쪽 기울기의 차(큰 것에서 작은 것을 뺀 값)를 구하시오.</p>

## 발상

2단과 똑같은데 <span class="m">f</span>의 기울기만 <span class="m">1</span>에서 <span class="m">3</span>으로 바뀌었다. <b>답도 3배가 될 것</b>이라고 미리 짐작해 보고, 실제로 그런지 확인한다.

## 풀이

<p><span class="step">①</span> <span class="m">x ≥ 0 → g(x) = −3x</span> (기울기 <span class="m">−3</span>), &nbsp; <span class="m">x &lt; 0 → g(x) = 21x</span> (기울기 <span class="m">21</span>)</p>
<p><span class="step">②</span> 차 <span class="m">= 21 − (−3) = 24</span></p>
<p><span class="step">③ 부호까지.</span> 뛰기 <span class="m">= (−3) − 21 = −24 = −8 × 3</span></p>

<p>2단에서는 <span class="m">f</span>의 기울기가 1이라 뛰기가 <span class="m">−8</span>이었고, 여기서는 3이라 <span class="m">−24</span>가 됐다. 즉</p>
<p class="m">뛰기 = −8 × (그 점에서 f의 기울기)</p>

<p>원문항에서 <span class="m">f</span>는 직선이 아니라 삼차함수지만, <b>한 점 근처만 아주 확대해 보면 어떤 곡선도 직선처럼 보인다.</b> 그때의 기울기를 <span class="m">f′(q)</span>라 쓸 뿐이고, 식은 그대로다.</p>
<p class="m">뛰기 = −8 f′(q)</p>

## 노하우

<b>원문항 풀이 ②의 <span class="m">−8f′(q)</span>는 여기서 나온 것이다.</b>
<span class="m">−8</span>은 배율의 차(<span class="m">−1</span>과 <span class="m">7</span>)에서, <span class="m">f′(q)</span>는 그 점에서 <span class="m">f</span>가 얼마나 가파른지에서 온다.
낯선 기호가 나오면 <b>기울기가 1인 가장 쉬운 경우를 먼저 해 보고, 몇 배가 되는지 확인</b>하면 된다.
