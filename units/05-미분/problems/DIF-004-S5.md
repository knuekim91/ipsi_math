## 문제

<p>함수 <span class="m">f(x) = x − 3</span>에 대하여 함수 <span class="m">g(x)</span>를</p>
<span class="cond m">g(x) = −f(x) (f(x) ≥ 0), &nbsp; g(x) = 7f(x) (f(x) &lt; 0)</span>
<p>이라 하자. 양수 <span class="m">k</span>에 대하여 함수 <span class="m">h(x) = g(x) + |k(x−3)|</span>가 실수 전체의 집합에서 미분가능할 때, <span class="m">k</span>의 값을 구하시오.</p>

## 발상

<b>두 개가 같은 자리(<span class="m">x = 3</span>)에서 꺾인다.</b> 하나는 아래로, 하나는 위로 꺾이니 <b>크기만 같으면 서로 지워진다.</b> 원문항이 하는 일이 정확히 이것이고, 여기서는 <span class="m">f</span>가 직선이라 계산이 눈에 보인다.

## 풀이

<p><span class="step">① g의 뛰기.</span> <span class="m">f(x) = x−3</span>이므로 <span class="m">x ≥ 3</span>에서 <span class="m">f ≥ 0</span>, <span class="m">x &lt; 3</span>에서 <span class="m">f &lt; 0</span>.</p>
<p class="m">x ≥ 3 : g = −(x−3) → 기울기 −1</p>
<p class="m">x &lt; 3 : g = 7(x−3) → 기울기 7</p>
<p class="m">g의 뛰기 = (−1) − 7 = −8</p>
<p>(3단의 식 <span class="m">−8 f′</span>에서 <span class="m">f′ = 1</span>이므로 <span class="m">−8</span>. 맞는다.)</p>

<p><span class="step">② 절댓값의 뛰기.</span> <span class="m">k &gt; 0</span>이므로 <span class="m">|k(x−3)| = k|x−3|</span>. 왼쪽 기울기 <span class="m">−k</span>, 오른쪽 기울기 <span class="m">k</span>.</p>
<p class="m">절댓값의 뛰기 = k − (−k) = 2k</p>

<p><span class="step">③ 더해서 0.</span> 두 함수를 더하면 뛰기도 더해진다. 매끄러우려면 합이 0이어야 하므로</p>
<p class="m">−8 + 2k = 0 → k = 4</p>

<p><span class="step">④ 확인.</span> <span class="m">k = 4</span>일 때 <span class="m">x = 3</span>의 왼쪽 기울기는 <span class="m">7 + (−4) = 3</span>, 오른쪽은 <span class="m">−1 + 4 = 3</span>. 같으므로 꺾이지 않는다.</p>

## 함정

<span class="m">g</span>의 뛰기가 음수, 절댓값의 뛰기가 양수라는 <b>부호</b>를 놓치면 <span class="m">8 + 2k = 0</span> 같은 식을 세워 답이 안 나온다. <b>두 뛰기는 반대 방향이어야 지워진다</b>는 것이 이 문제의 전부다.

## 노하우

<b>미분가능 조건은 &lsquo;뛰기의 합 = 0&rsquo;이라는 <u>방정식 한 개</u>다.</b>
꺾이는 점을 모두 찾고, 각 점에서 뛰기를 부호까지 살려 더한 뒤 0으로 놓는다.
원문항은 여기에 <span class="m">f</span>가 삼차함수라는 것과, 꺾이는 점이 하나만 남도록 근을 겹쳐야 한다는 조건이 얹혔을 뿐 구조는 이 문제와 똑같다.
