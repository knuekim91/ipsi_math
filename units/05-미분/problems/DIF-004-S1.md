## 문제

<p>함수 <span class="m">y = |2x|</span>에 대하여 <span class="m">x = 0</span>에서 <b>왼쪽에서 온 기울기</b>와 <b>오른쪽으로 가는 기울기</b>를 각각 구하고, 두 기울기의 차(큰 것에서 작은 것을 뺀 값)를 구하시오.</p>

## 발상

<b><span class="m">|2x|</span>는 사실 직선 두 개를 이어 붙인 것</b>이다. 오른쪽 반과 왼쪽 반을 따로 떼어 보면 그냥 일차함수라, 기울기는 <span class="m">x</span> 앞의 수 그대로다.

## 풀이

<p><span class="step">① 절댓값을 벗긴다.</span> 절댓값 안이 양수면 그대로, 음수면 부호를 뒤집는다.</p>
<p class="m">x ≥ 0 : 2x ≥ 0 → y = 2x &nbsp;(기울기 2)</p>
<p class="m">x &lt; 0 : 2x &lt; 0 → y = −2x &nbsp;(기울기 −2)</p>

<p><span class="step">② 두 기울기를 나란히.</span></p>
<p class="m">왼쪽에서 온 기울기 = −2, &nbsp; 오른쪽으로 가는 기울기 = 2</p>

<p><span class="step">③ 차.</span> <span class="m">2 − (−2) = 4</span></p>

<p>기울기가 <span class="m">−2</span>로 내려오다가 <span class="m">2</span>로 확 바뀌니 그 점에서 <b>뾰족하게 꺾인다.</b> 두 값이 같았다면 매끄럽게 이어졌을 것이다.</p>

## 노하우

<b>"미분가능하지 않다"는 말은 어렵게 들리지만, 뜻은 하나다 — <u>왼쪽 기울기와 오른쪽 기울기가 다르다</u>.</b>
두 값을 각각 구해 나란히 적는 습관만 들이면 이 단원의 절반이 끝난다.
그 차이를 앞으로 <b>&lsquo;뛰기&rsquo;</b>라고 부르겠다. 뛰기가 0이면 매끄럽고, 0이 아니면 꺾인 것이다.
