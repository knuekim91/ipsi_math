## 문제

<p>함수 <span class="m">f(x) = x</span>에 대하여 함수 <span class="m">g(x)</span>를 다음과 같이 정한다.</p>
<span class="cond m">g(x) = −f(x) (f(x) ≥ 0), &nbsp; g(x) = 7f(x) (f(x) &lt; 0)</span>
<p><span class="m">x = 0</span>에서 <span class="m">g</span>의 왼쪽 기울기와 오른쪽 기울기의 차(큰 것에서 작은 것을 뺀 값)를 구하시오.</p>

## 발상

<b><span class="m">f(x) = x</span>는 <span class="m">x</span>가 0보다 크면 양수, 작으면 음수</b>다. 그러니 <span class="m">x = 0</span>을 경계로 <span class="m">g</span>의 정의가 갈린다. 양쪽 다 직선이라 기울기는 눈으로 읽힌다.

## 풀이

<p><span class="step">① 어느 쪽이 어느 식인가.</span></p>
<p class="m">x ≥ 0 이면 f(x) = x ≥ 0 → g(x) = −x</p>
<p class="m">x &lt; 0 이면 f(x) = x &lt; 0 → g(x) = 7x</p>

<p><span class="step">② 기울기를 읽는다.</span></p>
<p class="m">왼쪽 기울기 = 7, &nbsp; 오른쪽 기울기 = −1</p>

<p><span class="step">③ 차.</span> <span class="m">7 − (−1) = 8</span></p>

<p><span class="step">④ 부호까지 살려 쓰면.</span> 뛰기를 <b>(오른쪽) − (왼쪽)</b>으로 정하면</p>
<p class="m">(−1) − 7 = −8</p>
<p>이 <b>−8</b>이 바로 원문항에 나오는 그 −8이다. <span class="m">−1</span>배와 <span class="m">7</span>배의 차이가 <span class="m">−1 − 7 = −8</span>이기 때문이다.</p>

## 함정

<span class="m">g(x) = −f(x)</span>라고 해서 "기울기도 그냥 반대"라고만 보면 안 된다. <b>왼쪽은 <span class="m">7</span>배, 오른쪽은 <span class="m">−1</span>배로 배율이 서로 다르다.</b> 두 배율이 다르기 때문에 꺾이는 것이다. 만약 양쪽 다 <span class="m">−1</span>배였다면 <span class="m">g = −f</span>로 매끄러웠을 것이다.

## 노하우

<b>구간별로 다른 수를 곱하면, 기울기도 그 수만큼 곱해진다.</b>
왼쪽 배율이 <span class="m">7</span>, 오른쪽 배율이 <span class="m">−1</span>이면 뛰기는 <span class="m">(−1 − 7) × (원래 기울기)</span>다.
<b>배율의 차 <span class="m">−8</span>은 문제가 정해준 상수</b>이므로, 남는 것은 "원래 기울기가 얼마인가"뿐이다.
