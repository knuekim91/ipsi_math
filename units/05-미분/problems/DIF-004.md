## 문제

<p>최고차항의 계수가 1인 삼차함수 <span class="m">f(x)</span>가 다음 조건을 만족시킬 때, <span class="m">f(0)</span>의 최댓값과 최솟값의 곱을 구하시오.</p><span class="cond m">(가) 방정식 f(x) = 0의 서로 다른 실근의 개수는 2이다.</span><span class="cond m">(나) g(x) = −f(x) (f(x) ≥ 0), 7f(x) (f(x) &lt; 0)일 때, 어떤 실수 a에 대하여 h(x) = g(x) + |(x−1)(x−a)(x−4+a)| 가 실수 전체의 집합에서 미분가능하다.</span>

## 발상

<b>두 함수 모두 부호가 바뀌는 점에서만 꺾인다.</b> g는 f의 단순근 한 곳에서만 꺾이므로 |P|도 꺾이는 곳이 정확히 그 한 점이어야 하고(→ P는 중근을 가져야 함), 두 꺾임이 상쇄되어야 한다.

## 풀이

<p><span class="step">① f의 모양을 정한다.</span>
삼차함수인데 <span class="m">f(x) = 0</span>의 서로 다른 실근이 <span class="m">2</span>개이므로
근 하나는 <b>중근</b>, 다른 하나는 <b>단순근</b>이다.
최고차항의 계수가 <span class="m">1</span>이므로</p>
<p class="m">f(x) = (x − p)<sup>2</sup>(x − q), &nbsp; p ≠ q</p>

<p><span class="step">② g가 어디서 꺾이는지 본다.</span>
<span class="m">g</span>는 <span class="m">f</span>의 부호에 따라 배율이 달라진다.
<span class="m">f ≥ 0</span>이면 <span class="m">−1</span>배, <span class="m">f &lt; 0</span>이면 <span class="m">7</span>배다.
따라서 <b><span class="m">f</span>의 부호가 바뀌는 곳에서만</b> 꺾일 수 있다.</p>
<p>중근 <span class="m">p</span>에서는 <span class="m">f</span>가 부호를 바꾸지 않고 게다가 <span class="m">f′(p) = 0</span>이라
좌우 미분계수가 모두 <span class="m">0</span>이 되어 <b>꺾이지 않는다.</b></p>
<p>남은 것은 단순근 <span class="m">q</span> 한 곳이다. 그곳의 좌우 미분계수를 계산하면</p>
<p class="m">g′(q<sup>−</sup>) = 7f′(q), &nbsp; g′(q<sup>+</sup>) = −f′(q)</p>
<p>차이(&lsquo;뛰기&rsquo;)는</p>
<p class="m">g′(q<sup>+</sup>) − g′(q<sup>−</sup>) = −f′(q) − 7f′(q) = −8f′(q)</p>

<p><span class="step">③ 절댓값 부분이 어디서 꺾이는지 본다.</span>
<span class="m">P(x) = (x−1)(x−a)(x−4+a)</span>라 하면
<span class="m">|P|</span>도 <b><span class="m">P</span>가 부호를 바꾸는 단순근에서만</b> 꺾인다.</p>
<p><span class="m">h = g + |P|</span>가 <b>모든 실수에서</b> 미분가능하려면,
두 꺾임이 <b>같은 자리에서 서로 상쇄</b>되어야 한다.
그러려면 <span class="m">|P|</span>가 꺾이는 곳도 <b>정확히 한 점</b>이어야 하므로
<span class="m">P</span>의 세 근 <span class="m">1, a, 4−a</span> 중 <b>둘이 겹쳐야</b> 한다.</p>
<p class="m">a = 1 → 근 1, 1, 3 → 단순근은 x = 3</p>
<p class="m">a = 3 → 근 1, 3, 1 → 단순근은 x = 3</p>
<p class="m">a = 2 → 근 1, 2, 2 → 단순근은 x = 1</p>

<p><span class="step">④ 상쇄 조건을 식으로 쓴다.</span>
<span class="m">|P|</span>의 단순근 <span class="m">q</span>에서의 뛰기는
<span class="m">2|P′(q)|</span>이다. (음수 쪽 기울기가 부호를 바꾸므로 두 배가 된다.)
두 뛰기의 합이 <span class="m">0</span>이어야 하므로</p>
<p class="m">−8f′(q) + 2|P′(q)| = 0</p>
<p><span class="m">f(x) = (x−p)<sup>2</sup>(x−q)</span>이므로
<span class="m">f′(q) = (q − p)<sup>2</sup></span>이다. 이를 넣으면</p>
<p class="m">|P′(q)| = 4(q − p)<sup>2</sup></p>

<p><span class="step">⑤ 두 경우를 계산한다.</span></p>
<p><b>[경우 1] 단순근이 <span class="m">q = 1</span> (<span class="m">a = 2</span>)</b></p>
<p class="m">P(x) = (x−1)(x−2)<sup>2</sup> → P′(1) = (1−2)<sup>2</sup> = 1</p>
<p class="m">4(1 − p)<sup>2</sup> = 1 → (1 − p)<sup>2</sup> = 1/4 → p = 1/2 또는 p = 3/2</p>
<p><span class="m">f(0) = (0−p)<sup>2</sup>(0−q) = −p<sup>2</sup></span>이므로</p>
<p class="m">p = 1/2 → f(0) = −1/4, &nbsp; p = 3/2 → f(0) = −9/4</p>

<p><b>[경우 2] 단순근이 <span class="m">q = 3</span> (<span class="m">a = 1</span> 또는 <span class="m">a = 3</span>)</b></p>
<p class="m">P(x) = (x−1)<sup>2</sup>(x−3) → P′(3) = (3−1)<sup>2</sup> = 4</p>
<p class="m">4(3 − p)<sup>2</sup> = 4 → (3 − p)<sup>2</sup> = 1 → p = 2 또는 p = 4</p>
<p class="m">f(0) = −3p<sup>2</sup> → p = 2 → f(0) = −12, &nbsp; p = 4 → f(0) = −48</p>

<p><span class="step">⑥ 최댓값과 최솟값을 고른다.</span>
나온 값은 <span class="m">−1/4, −9/4, −12, −48</span> 네 개다.</p>
<p class="m">최댓값 = −1/4, &nbsp; 최솟값 = −48</p>
<p class="m">(−1/4) × (−48) = 12</p>
<p class="m">답 12</p>

## 다른 풀이

<p><span class="step">뛰기를 한 번도 쓰지 않는 길.</span> 좌우 기울기를 재는 대신, <b>식을 하나로 묶어 &lsquo;절댓값 앞의 계수&rsquo;만 0으로 놓는다.</b></p>

<p><span class="step">① g에서 경우 나눔을 없앤다.</span> <span class="m">g = pf + q|f|</span>로 두면 <span class="m">f ≥ 0</span>일 때 <span class="m">(p+q)f = −f</span>, <span class="m">f &lt; 0</span>일 때 <span class="m">(p−q)f = 7f</span>이므로</p>
<p class="m">p + q = −1, &nbsp; p − q = 7 → p = 3, q = −4</p>
<p class="m"><b>g(x) = 3f(x) − 4|f(x)|</b></p>

<p><span class="step">② 볼 것을 줄인다.</span> <span class="m">3f</span>는 다항식이라 어디서나 미분가능하다. 따라서</p>
<p class="m">h = 3f − 4|f| + |P| 가 미분가능 ⟺ −4|f| + |P| 가 미분가능</p>

<p><span class="step">③ 두 절댓값의 모양을 맞춘다.</span> <span class="m">f = (x−p<sub>0</sub>)<sup>2</sup>(x−q)</span>이고 <span class="m">(x−p<sub>0</sub>)<sup>2</sup> ≥ 0</span>이므로</p>
<p class="m">|f| = (x−p<sub>0</sub>)<sup>2</sup>|x−q|</p>
<p>이 항은 <span class="m">x = q</span>에서만 꺾인다. 이것을 지우려면 <span class="m">|P|</span>도 <b>같은 <span class="m">|x−q|</span>를 가진 꼴</b>이어야 하므로, <span class="m">P</span>는 <b>중근 <span class="m">r</span> 하나와 단근 <span class="m">q</span></b>를 가져야 한다.</p>
<p class="m">|P| = (x−r)<sup>2</sup>|x−q|</p>
<p><span class="m">P</span>의 근은 <span class="m">1, a, 4−a</span>이므로 둘이 겹쳐야 한다 → <span class="m">a = 2</span>(근 1, 2, 2) 또는 <span class="m">a = 1, 3</span>(근 1, 1, 3).</p>

<p><span class="step">④ 계수 하나로 묶는다.</span></p>
<p class="m">−4|f| + |P| = [ (x−r)<sup>2</sup> − 4(x−p<sub>0</sub>)<sup>2</sup> ] |x−q|</p>
<p><span class="m">A(x)|x−q|</span>는 <span class="m">A(q) = 0</span>일 때만 미분가능하므로</p>
<p class="m">(q−r)<sup>2</sup> = 4(q−p<sub>0</sub>)<sup>2</sup> → <b>|q − r| = 2|q − p<sub>0</sub>|</b></p>

<p><span class="step">⑤ 적용.</span> <b>&lsquo;단근에서 중근까지의 거리 = 단근에서 f의 중근까지 거리의 2배&rsquo;</b></p>
<p class="m">a = 2 : q = 1, r = 2 → |1−2| = 1 = 2|1−p<sub>0</sub>| → p<sub>0</sub> = ½, 3/2 → f(0) = −¼, −9/4</p>
<p class="m">a = 1 또는 3 : q = 3, r = 1 → |3−1| = 2 = 2|3−p<sub>0</sub>| → p<sub>0</sub> = 2, 4 → f(0) = −12, −48</p>
<p class="m">(−¼) × (−48) = 12</p>

<p><b>미분이라는 말이 한 번도 나오지 않는다.</b> 필요한 것은 &lsquo;절댓값 앞의 계수를 0으로&rsquo; 하나뿐이고, 마지막 조건도 <b>거리의 2배</b>라는 그림으로 읽힌다.</p>

## 함정

<b>풀이 ②의 <span class="m">−8f′(q)</span>가 어디서 나왔는지가 이 문제의 첫 고비다.</b> 큰 것을 보지 말고 <b>그 점 바로 옆만 확대</b>해 보면 된다.

<p><span class="m">g</span>는 <span class="m">f</span>의 부호에 따라 배율이 달라진다. <span class="m">f ≥ 0</span>이면 <span class="m">−1</span>배, <span class="m">f &lt; 0</span>이면 <span class="m">7</span>배. 그런데 <b>기울기도 곱한 수만큼 곱해진다.</b> 그러니 단순근 <span class="m">q</span>의 좌우에서</p>

<p class="m">왼쪽(f &lt; 0) 기울기 = 7 f′(q), &nbsp; 오른쪽(f &gt; 0) 기울기 = −f′(q)</p>

<p>이고, 그 차이(뛰기)는</p>

<p class="m">(−f′(q)) − 7f′(q) = −8 f′(q)</p>

<p>가 된다. <b><span class="m">−8</span>은 배율의 차(<span class="m">−1 − 7</span>)일 뿐</b>이고, <span class="m">f′(q)</span>는 그 점에서 <span class="m">f</span>가 얼마나 가파른지다. 헷갈리면 <b><span class="m">f(x) = x</span>처럼 가장 쉬운 직선</b>으로 바꿔 손으로 확인해 보면 바로 보인다.</p>

<p>중근 <span class="m">p</span>에서 꺾이지 않는 이유도 같다. 거기서는 <span class="m">f′(p) = 0</span>이라 <b>뛰기가 <span class="m">−8 × 0 = 0</span></b>이다.</p>

## 노하우

<b>절댓값·구간별 정의 함수의 미분가능성은 &lsquo;꺾이는 점의 목록&rsquo;에서 시작한다.</b> 꺾임을 <b>좌우 도함수의 차이(뛰기)</b>라는 하나의 수로 관리하면 킬러가 일차방정식으로 줄어든다. 부호가 바뀌지 않는 중근에서는 애초에 꺾이지 않는다.
