## 문제

<p>함수 <span class="m">f(x)</span>에 대하여 함수 <span class="m">g(x)</span>를</p>
<span class="cond m">g(x) = −f(x) (f(x) ≥ 0), &nbsp; g(x) = 7f(x) (f(x) &lt; 0)</span>
<p>이라 하자. 모든 실수 <span class="m">x</span>에 대하여</p>
<p class="m">g(x) = p f(x) + q |f(x)|</p>
<p>가 성립할 때, <span class="m">p − q</span>의 값을 구하시오. (단, <span class="m">p, q</span>는 상수)</p>

## 발상

<b><span class="m">|f|</span>는 <span class="m">f ≥ 0</span>이면 <span class="m">f</span>, <span class="m">f &lt; 0</span>이면 <span class="m">−f</span></b>다. 그러니 <span class="m">pf + q|f|</span>도 두 경우로 갈리고, 그 두 값을 각각 <span class="m">−f</span>와 <span class="m">7f</span>에 맞추면 된다.

## 풀이

<p><span class="step">① 두 경우를 써 본다.</span></p>
<p class="m">f ≥ 0 : pf + qf = (p+q)f &nbsp;→&nbsp; −f 와 같아야 하므로 p + q = −1</p>
<p class="m">f &lt; 0 : pf − qf = (p−q)f &nbsp;→&nbsp; 7f 와 같아야 하므로 p − q = 7</p>

<p><span class="step">② 답.</span> 묻는 것이 바로 두 번째 식이다.</p>
<p class="m">p − q = 7</p>
<p>(덧붙여 두 식을 풀면 <span class="m">p = 3, q = −4</span>. 즉 <span class="m">g = 3f − 4|f|</span>이다.)</p>

## 노하우

<b>부호에 따라 갈린 정의는 언제나 <span class="m">pf + q|f|</span> 꼴 하나로 묶을 수 있다.</b>
<span class="m">p+q</span>는 양수 쪽 배율, <span class="m">p−q</span>는 음수 쪽 배율이다.
묶고 나면 <b>경우를 나눌 일이 사라지고</b>, 미분가능성은 <span class="m">|f|</span> 하나만 보면 되는 문제로 바뀐다.
이것이 이 단원에서 가장 크게 시간을 줄여 주는 손놀림이다.
