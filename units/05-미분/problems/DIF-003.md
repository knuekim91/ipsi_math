## 문제

<p class="m">기울기가 8이고 y절편이 양수인 직선이 곡선 y = x<sup>3</sup> − 3x<sup>2</sup> − x + 2에 접할 때, 이 직선은 점 (1, k)를 지난다. k의 값을 구하시오.</p>

## 발상

f′(x) = 8 에서 접점 후보가 <b>두 개</b> 나온다. &lsquo;y절편이 양수&rsquo;가 하나를 버리라는 지시다.

## 풀이

<p><span class="step">① 접점을 찾는다.</span>
직선이 곡선에 접한다는 것은 <b>접점에서의 미분계수가 그 직선의 기울기와 같다</b>는 뜻이다.
기울기가 <span class="m">8</span>이므로 <span class="m">f′(x) = 8</span>인 <span class="m">x</span>를 찾는다.</p>
<p class="m">y′ = 3x<sup>2</sup> − 6x − 1</p>
<p class="m">3x<sup>2</sup> − 6x − 1 = 8</p>
<p>오른쪽 <span class="m">8</span>을 왼쪽으로 넘긴다.</p>
<p class="m">3x<sup>2</sup> − 6x − 9 = 0</p>
<p>양변을 <span class="m">3</span>으로 나눈다.</p>
<p class="m">x<sup>2</sup> − 2x − 3 = 0 → (x − 3)(x + 1) = 0 → x = 3 또는 x = −1</p>
<p><b>접점 후보가 두 개</b> 나왔다. 문제의 &lsquo;<span class="m">y</span>절편이 양수&rsquo;가
<b>이 중 하나를 버리라는 지시</b>다.</p>

<p><span class="step">② 첫 번째 후보 x = 3을 확인한다.</span>
접점의 <span class="m">y</span>좌표를 구한다.</p>
<p class="m">y(3) = 27 − 27 − 3 + 2 = −1</p>
<p>기울기 <span class="m">8</span>, 점 <span class="m">(3, −1)</span>을 지나는 직선은</p>
<p class="m">y = 8(x − 3) − 1 = 8x − 25</p>
<p><span class="m">y</span>절편이 <span class="m">−25</span>로 음수이므로 <b>탈락</b>이다.</p>

<p><span class="step">③ 두 번째 후보 x = −1을 확인한다.</span></p>
<p class="m">y(−1) = −1 − 3 + 1 + 2 = −1</p>
<p class="m">y = 8(x + 1) − 1 = 8x + 7</p>
<p><span class="m">y</span>절편이 <span class="m">7</span>로 양수이므로 <b>이것이 구하는 직선</b>이다.</p>

<p><span class="step">④ 점 (1, k)를 대입한다.</span></p>
<p class="m">k = 8 × 1 + 7 = 15</p>
<p class="m">답 15</p>

## 다른 풀이

<p><span class="step">미분하지 않고 중근 조건으로.</span> 접선을 <span class="m">y = 8x + c</span>라 두면, 접한다는 것은 곡선과 직선의 교점 방정식이 <b>중근</b>을 갖는다는 뜻이다.</p>

<p class="m">x<sup>3</sup> − 3x<sup>2</sup> − x + 2 = 8x + c → x<sup>3</sup> − 3x<sup>2</sup> − 9x + (2 − c) = 0</p>

<p>세 근을 <span class="m">α, α, β</span>라 하면 근과 계수의 관계에서</p>
<p class="m">2α + β = 3, &nbsp; α<sup>2</sup> + 2αβ = −9, &nbsp; α<sup>2</sup>β = c − 2</p>

<p>첫 식을 둘째에 넣으면 <span class="m">−3α<sup>2</sup> + 6α = −9 → α<sup>2</sup> − 2α − 3 = 0 → α = 3, −1</span></p>

<p class="m">α = 3 → β = −3, c = 2 + 9(−3) = −25 (탈락)</p>
<p class="m">α = −1 → β = 5, c = 2 + 1·5 = 7 (채택) → k = 8 + 7 = 15</p>

<p><b>y절편 c가 계산 과정에서 바로 나온다</b>는 것이 장점이다. 본 풀이는 접점을 구한 뒤 접선을 따로 세워야 하지만, 이 방법은 c를 직접 얻으므로 "y절편이 양수" 조건을 <b>더 빨리</b> 적용할 수 있다.</p>

## 노하우

<b>접점 후보가 둘 이상이면 반드시 거른다.</b> 문제에 붙은 부호 조건(y절편이 양수, a&gt;1, 모든 항이 양수)은 예외 없이 그 필터다.
