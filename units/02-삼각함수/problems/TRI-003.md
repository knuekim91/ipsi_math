## 문제

<p class="m">0 ≤ x ≤ 2π에서 f(x) = sin x, g(x) = −k cos x (k&gt;1). 두 곡선의 제1사분면 교점을 A, 제4사분면 교점을 B, A를 지나 x축에 평행한 직선이 y=g(x)와 만나는 A가 아닌 점을 C, B를 지나 x축에 평행한 직선이 y=g(x)와 만나는 B가 아닌 점을 D라 하자. (삼각형 CDB) : (삼각형 AOD) = 14 : 5일 때, A의 x좌표를 a라 하면 B, D의 x좌표는 각각 p(a), q(a)이고 a = α이다. 3 × p(α)/q(α)의 값을 구하시오. (O는 원점)</p>

## 발상

A의 x좌표를 a라 두면 <b>y = −k cos x 는 x = π에 대해 대칭</b>이므로 같은 높이의 짝점이 2π−a, π−a로 즉시 나온다. B는 tan x = −k의 다음 해이므로 a+π.

## 풀이

<p><span class="step">① 교점의 x좌표가 만족하는 식을 세운다.</span>
두 곡선이 만나므로 <span class="m">sin x = −k cos x</span>이다.
양변을 <span class="m">cos x</span>로 나누면</p>
<p class="m">tan x = −k</p>
<p><span class="m">k &gt; 1</span>이므로 <span class="m">tan x</span>가 <span class="m">−1</span>보다 작아야 한다.</p>

<p><span class="step">② 점 A와 B의 좌표를 정한다.</span>
A는 제1사분면 교점이므로 <span class="m">y = sin x &gt; 0</span>, 곧 <span class="m">0 &lt; x &lt; π</span>이고,
<span class="m">tan x</span>가 음수여야 하므로 <span class="m">x ∈ (π/2, π)</span>이다.
이 <span class="m">x</span>좌표를 <span class="m">a</span>라 하자.</p>
<p class="m">A(a, sin a)</p>
<p><span class="m">tan</span>의 주기는 <span class="m">π</span>이므로 다음 해는 <span class="m">a + π</span>이고,
이때 <span class="m">sin(a+π) = −sin a &lt; 0</span>이라 <b>제4사분면 점</b>이 된다.</p>
<p class="m">B(a + π, −sin a) &nbsp; 따라서 &nbsp; p(a) = a + π</p>

<p><span class="step">③ 대칭을 이용해 C와 D를 찾는다.</span>
<b><span class="m">y = −k cos x</span>는 <span class="m">x = π</span>에 대해 좌우대칭</b>이다.
(<span class="m">cos(2π − x) = cos x</span>이기 때문이다.)
따라서 어떤 점 <span class="m">x</span>와 그 짝 <span class="m">2π − x</span>는 <b>같은 높이</b>에 있다.</p>
<p>C는 A와 같은 높이인 다른 점이므로 A의 짝이다.</p>
<p class="m">C(2π − a, sin a)</p>
<p>D는 B와 같은 높이인 다른 점이므로 B의 짝이다.</p>
<p class="m">D(2π − (a + π), −sin a) = D(π − a, −sin a) &nbsp; 따라서 &nbsp; q(a) = π − a</p>

<p><span class="step">④ 삼각형 CDB의 넓이를 구한다.</span>
D와 B는 <span class="m">y</span>좌표가 <span class="m">−sin a</span>로 같으므로
선분 DB가 <b>수평인 밑변</b>이다.</p>
<p class="m">DB = (a + π) − (π − a) = 2a</p>
<p>높이는 C와 이 밑변의 <span class="m">y</span>좌표 차이다.</p>
<p class="m">높이 = sin a − (−sin a) = 2 sin a</p>
<p class="m">(삼각형 CDB) = ½ × 2a × 2 sin a = 2a sin a</p>

<p><span class="step">⑤ 삼각형 AOD의 넓이를 구한다.</span>
한 꼭짓점이 원점이므로 <b>두 점의 좌표만으로 넓이를 계산</b>할 수 있다.</p>
<p class="m">(삼각형 AOD) = ½ |x<sub>A</sub> y<sub>D</sub> − x<sub>D</sub> y<sub>A</sub>|</p>
<p class="m">= ½ |a(−sin a) − (π − a)(sin a)| = ½ |−a sin a − π sin a + a sin a| = ½ × π sin a</p>

<p><span class="step">⑥ 비를 놓고 a를 구한다.</span>
넓이의 비가 <span class="m">14 : 5</span>이므로</p>
<p class="m">2a sin a : (π/2) sin a = 14 : 5</p>
<p><b>양쪽에 있는 <span class="m">sin a</span>가 약분된다.</b>
(A가 제1사분면 점이라 <span class="m">sin a ≠ 0</span>이다.)</p>
<p class="m">2a : π/2 = 14 : 5</p>
<p>안쪽끼리, 바깥쪽끼리 곱한다.</p>
<p class="m">5 × 2a = 14 × π/2 → 10a = 7π → a = 7π/10</p>
<p>이 값이 <span class="m">α</span>이고, <span class="m">(π/2, π)</span> 안에 있으므로 조건에 맞는다.</p>

<p><span class="step">⑦ 구하는 값을 계산한다.</span></p>
<p class="m">p(α) = 7π/10 + π = 17π/10</p>
<p class="m">q(α) = π − 7π/10 = 3π/10</p>
<p class="m">3 × p(α)/q(α) = 3 × (17π/10) ÷ (3π/10) = 3 × 17/3 = 17</p>
<p class="m">답 17</p>

## 노하우

<b>수평선이 삼각함수 곡선을 자를 때 두 교점의 x좌표 합은 대칭축의 2배.</b> cos 계열의 대칭축은 x = 0, π, 2π. 넓이비에서는 sin a가 약분되어 각만 남는다.
