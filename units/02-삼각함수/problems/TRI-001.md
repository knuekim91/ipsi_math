## 문제

<p class="m">두 양수 a, b에 대하여 함수 f(x) = a sin(x/b) + 2의 최댓값이 5이고 주기가 8π일 때, a+b의 값은?</p><div class="choices"><span>① 6</span><span>② 25/4</span><span>③ 13/2</span><span>④ 27/4</span><span>⑤ 7</span></div>

## 발상

최댓값 = 진폭 + 평행이동, 주기 = 2π ÷ (x의 계수). 두 조건이 a와 b를 <b>따로</b> 결정한다.

## 풀이

<p><span class="step">① 두 조건이 각각 무엇을 정하는지 나눈다.</span>
<span class="m">f(x) = a sin(x/b) + 2</span>에서
<b>최댓값은 <span class="m">a</span>만</b> 관계하고 <b>주기는 <span class="m">b</span>만</b> 관계한다.
그러므로 <b>연립할 필요 없이 하나씩 따로</b> 구하면 된다.</p>

<p><span class="step">② 최댓값으로 a를 구한다.</span>
<span class="m">sin</span>의 값은 아무리 커도 <span class="m">1</span>이다.
<span class="m">a</span>가 양수이므로 <span class="m">a sin(x/b)</span>의 최댓값은 <span class="m">a × 1 = a</span>이고,
여기에 <span class="m">2</span>를 더한 것이 <span class="m">f(x)</span>의 최댓값이다.</p>
<p class="m">a + 2 = 5</p>
<p>양변에서 <span class="m">2</span>를 빼면</p>
<p class="m">a = 3</p>

<p><span class="step">③ 주기로 b를 구한다.</span>
<span class="m">y = sin(kx)</span>의 주기는 <span class="m">2π/|k|</span>이다.
여기서는 <span class="m">x</span>의 계수가 <span class="m">1/b</span>이므로 주기는</p>
<p class="m">2π ÷ (1/b) = 2πb</p>
<p>이 값이 <span class="m">8π</span>라 했으므로</p>
<p class="m">2πb = 8π</p>
<p>양변을 <span class="m">2π</span>로 나누면</p>
<p class="m">b = 4</p>

<p><span class="step">④ 답을 만든다.</span></p>
<p class="m">a + b = 3 + 4 = 7</p>
<p class="m">답 ⑤</p>

## 노하우

<b>y = a sin(bx+c)+d 는 최대 |a|+d, 최소 −|a|+d, 주기 2π/|b|</b>를 계산 없이 읽어낸다. a의 부호가 주어지지 않으면 절댓값을 잊지 않는다.
