## 문제

<p class="m">모든 항이 양수인 등비수열 {a<sub>n</sub>}의 첫째항부터 제n항까지의 합을 S<sub>n</sub>이라 하자. S<sub>3</sub> / (a<sub>1</sub> + 2a<sub>2</sub>) = 7/3일 때, a<sub>8</sub>/a<sub>6</sub>의 값은?</p><div class="choices"><span>① 4</span><span>② 9</span><span>③ 16</span><span>④ 25</span><span>⑤ 36</span></div>

## 발상

분자·분모를 a<sub>1</sub>로 묶으면 <b>a<sub>1</sub>이 약분되어 r만의 이차방정식</b>이 된다. 구하는 값도 r<sup>2</sup>이라 a<sub>1</sub>은 끝까지 불필요.

## 풀이

<p><span class="step">① 모든 항을 첫째항과 공비로 바꾼다.</span>
첫째항을 <span class="m">a<sub>1</sub></span>, 공비를 <span class="m">r</span>이라 하면
<span class="m">a<sub>2</sub> = a<sub>1</sub>r</span>,
<span class="m">a<sub>3</sub> = a<sub>1</sub>r<sup>2</sup></span>이다.
분자와 분모를 각각 <b><span class="m">a<sub>1</sub></span>으로 묶어</b> 쓴다.</p>
<p class="m">S<sub>3</sub> = a<sub>1</sub> + a<sub>1</sub>r + a<sub>1</sub>r<sup>2</sup> = a<sub>1</sub>(1 + r + r<sup>2</sup>)</p>
<p class="m">a<sub>1</sub> + 2a<sub>2</sub> = a<sub>1</sub> + 2a<sub>1</sub>r = a<sub>1</sub>(1 + 2r)</p>

<p><span class="step">② 분수를 만들면 첫째항이 약분된다.</span>
모든 항이 양수라 <span class="m">a<sub>1</sub> ≠ 0</span>이므로 약분할 수 있다.
<b>이 약분 덕분에 미지수가 <span class="m">r</span> 하나로 줄어든다.</b></p>
<p class="m">S<sub>3</sub> / (a<sub>1</sub> + 2a<sub>2</sub>) = (1 + r + r<sup>2</sup>) / (1 + 2r) = 7/3</p>

<p><span class="step">③ 분모를 없앤다.</span>
양변에 <span class="m">3(1 + 2r)</span>을 곱한다. (대각선끼리 곱하는 것과 같다.)</p>
<p class="m">3(1 + r + r<sup>2</sup>) = 7(1 + 2r)</p>
<p class="m">3 + 3r + 3r<sup>2</sup> = 7 + 14r</p>

<p><span class="step">④ 한쪽으로 모아 이차방정식을 만든다.</span>
오른쪽의 <span class="m">7</span>과 <span class="m">14r</span>을 왼쪽으로 넘긴다.</p>
<p class="m">3r<sup>2</sup> + 3r − 14r + 3 − 7 = 0</p>
<p class="m">3r<sup>2</sup> − 11r − 4 = 0</p>

<p><span class="step">⑤ 인수분해해서 공비를 구한다.</span></p>
<p class="m">(3r + 1)(r − 4) = 0 → r = −1/3 또는 r = 4</p>
<p><b>모든 항이 양수</b>라는 조건이 있으므로 공비도 양수여야 한다.
<span class="m">r = −1/3</span>은 버린다.</p>
<p class="m">r = 4</p>

<p><span class="step">⑥ 구하는 값을 만든다.</span>
<span class="m">a<sub>8</sub> = a<sub>1</sub>r<sup>7</sup></span>,
<span class="m">a<sub>6</sub> = a<sub>1</sub>r<sup>5</sup></span>이므로
나누면 <b>첫째항은 또 약분되고 지수만 빼면 된다.</b></p>
<p class="m">a<sub>8</sub>/a<sub>6</sub> = a<sub>1</sub>r<sup>7</sup> / (a<sub>1</sub>r<sup>5</sup>) = r<sup>7−5</sup> = r<sup>2</sup> = 4<sup>2</sup> = 16</p>
<p class="m">답 ③</p>

## 함정

<span class='m'>r = −1/3</span>을 버리는 근거는 &lsquo;모든 항이 양수&rsquo;. 조건 문장 하나가 근을 거르는 장치다.

## 노하우

등비수열의 비율 조건은 <b>a<sub>1</sub>을 약분해 r만의 방정식</b>으로. 구하는 값이 a<sub>m</sub>/a<sub>n</sub>이면 답은 언제나 r<sup>m−n</sup>.
