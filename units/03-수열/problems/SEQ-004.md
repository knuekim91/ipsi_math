## 문제

<p class="m">실수 전체에서 정의된 함수 f(x) = 5 (x가 자연수가 아닌 경우), 1/x (x가 자연수인 경우)에 대하여, Σ<sub>k=1</sub><sup>n</sup> f(∛k)/(5f(k))의 값이 자연수가 되도록 하는 300 이하의 자연수 n의 개수는?</p><div class="choices"><span>① 135</span><span>② 144</span><span>③ 153</span><span>④ 162</span><span>⑤ 171</span></div>

## 발상

k는 항상 자연수이므로 분모는 늘 5/k. 분자만 갈라지는데 <b>∛k가 자연수인 경우는 k가 완전세제곱일 때뿐</b>이다.

## 풀이

<p><span class="step">① 분모부터 정리한다.</span>
더하는 항은 <span class="m">f(∛k) / (5f(k))</span>이다.
여기서 <span class="m">k</span>는 <span class="m">1</span>부터 <span class="m">n</span>까지의 <b>자연수</b>이므로
<span class="m">f(k)</span>는 언제나 <span class="m">1/k</span> 쪽 정의를 쓴다.</p>
<p class="m">5f(k) = 5 × (1/k) = 5/k &nbsp; (모든 k에 대해 같은 꼴)</p>
<p><b>갈라지는 것은 분자뿐</b>이다.</p>

<p><span class="step">② 분자가 갈라지는 기준을 찾는다.</span>
<span class="m">f(∛k)</span>는 <span class="m">∛k</span>가 자연수인지에 따라 달라진다.
<span class="m">∛k</span>가 자연수라는 것은 <b><span class="m">k</span>가 어떤 자연수의 세제곱</b>이라는 뜻이다.</p>

<p><b>㉠ <span class="m">k</span>가 완전세제곱이 아닐 때</b> — <span class="m">f(∛k) = 5</span>이므로</p>
<p class="m">항 = 5 ÷ (5/k) = 5 × k/5 = k</p>

<p><b>㉡ <span class="m">k = m<sup>3</sup></span>일 때</b> — <span class="m">∛k = m</span>이 자연수이므로
<span class="m">f(∛k) = 1/m</span>이고 <span class="m">5f(k) = 5/m<sup>3</sup></span>이다.</p>
<p class="m">항 = (1/m) ÷ (5/m<sup>3</sup>) = (1/m) × (m<sup>3</sup>/5) = m<sup>2</sup>/5</p>

<p><span class="step">③ 합을 &lsquo;전부 k로 더한 뒤 고치는&rsquo; 방식으로 쓴다.</span>
<span class="m">m<sup>3</sup> ≤ n</span>을 만족시키는 가장 큰 자연수를 <span class="m">M</span>이라 하자.
일단 모든 항을 ㉠처럼 <span class="m">k</span>로 더해 놓고,
완전세제곱인 자리만 <b><span class="m">k = m<sup>3</sup></span>을 빼고 <span class="m">m<sup>2</sup>/5</span>을 더해</b> 바로잡는다.</p>
<p class="m">S<sub>n</sub> = Σ<sub>k=1</sub><sup>n</sup>k − Σ<sub>m=1</sub><sup>M</sup>m<sup>3</sup> + (1/5)Σ<sub>m=1</sub><sup>M</sup>m<sup>2</sup></p>

<p><span class="step">④ 조건을 하나로 줄인다.</span>
앞의 두 덩어리는 자연수의 합이라 <b>언제나 정수</b>다.
그러므로 <span class="m">S<sub>n</sub></span>이 자연수가 될 조건은 마지막 덩어리에만 달려 있다.</p>
<p class="m">Σ<sub>m=1</sub><sup>M</sup>m<sup>2</sup> 이 5의 배수</p>

<p><span class="step">⑤ M의 값을 하나씩 확인한다.</span>
<span class="m">n ≤ 300</span>이고 <span class="m">6<sup>3</sup> = 216 ≤ 300</span>,
<span class="m">7<sup>3</sup> = 343 &gt; 300</span>이므로 <span class="m">M</span>은 <span class="m">1</span>부터 <span class="m">6</span>까지만 본다.</p>
<p class="m">M = 1 : 1 &nbsp; / &nbsp; M = 2 : 5 &nbsp; / &nbsp; M = 3 : 14</p>
<p class="m">M = 4 : 30 &nbsp; / &nbsp; M = 5 : 55 &nbsp; / &nbsp; M = 6 : 91</p>
<p>이 중 <span class="m">5</span>의 배수는 <span class="m">5, 30, 55</span>이므로</p>
<p class="m">M = 2, 4, 5</p>

<p><span class="step">⑥ 각 M에 해당하는 n의 개수를 센다.</span>
<span class="m">M</span>이 어떤 값이라는 것은
<span class="m">M<sup>3</sup> ≤ n &lt; (M+1)<sup>3</sup></span>이라는 뜻이다.</p>
<p class="m">M = 2 : 8 ≤ n ≤ 26 → 26 − 8 + 1 = 19개</p>
<p class="m">M = 4 : 64 ≤ n ≤ 124 → 124 − 64 + 1 = 61개</p>
<p class="m">M = 5 : 125 ≤ n ≤ 215 → 215 − 125 + 1 = 91개</p>
<p class="m">19 + 61 + 91 = 171</p>
<p class="m">답 ⑤</p>

## 노하우

<b>&lsquo;자연수일 때만 다르게 정의된 함수&rsquo;는 예외 항을 통째로 빼고 다시 더한다.</b> 그러면 정수 판정이 분모에 남는 항 하나로 압축되고, 남는 일은 구간별 개수 세기뿐이다.
