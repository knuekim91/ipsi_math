## 문제

<p class="m">2<sup>3/2</sup> × 4<sup>−1/2</sup>의 값은?</p><div class="choices"><span>① 2<sup>−1</sup></span><span>② 2<sup>−1/2</sup></span><span>③ 1</span><span>④ 2<sup>1/2</sup></span><span>⑤ 2</span></div>

## 발상

4를 2<sup>2</sup>으로 바꾸는 순간 끝난다. 밑이 다른 채로 계산을 시작하지 않는다.

## 풀이

<p><span class="step">① 밑이 서로 다르다는 것을 먼저 확인한다.</span>
곱해지는 두 수는 <span class="m">2<sup>3/2</sup></span>과 <span class="m">4<sup>−1/2</sup></span>이고,
밑이 각각 <span class="m">2</span>와 <span class="m">4</span>로 다르다.
<b>밑이 다르면 지수끼리 더할 수 없으므로</b> 먼저 밑을 하나로 통일해야 한다.
<span class="m">4 = 2<sup>2</sup></span>이므로 밑을 <span class="m">2</span>로 맞춘다.</p>

<p><span class="step">② 뒤쪽 수의 밑을 2로 바꾼다.</span>
<span class="m">4</span> 대신 <span class="m">2<sup>2</sup></span>을 넣고
지수법칙 <span class="m">(a<sup>m</sup>)<sup>n</sup> = a<sup>mn</sup></span>을 쓴다.
<b>겹친 지수는 곱한다.</b></p>
<p class="m">4<sup>−1/2</sup> = (2<sup>2</sup>)<sup>−1/2</sup> = 2<sup>2 × (−1/2)</sup> = 2<sup>−1</sup></p>

<p><span class="step">③ 밑이 같아졌으므로 지수를 더한다.</span>
이제 두 수 모두 밑이 <span class="m">2</span>이다.
지수법칙 <span class="m">a<sup>m</sup> × a<sup>n</sup> = a<sup>m+n</sup></span>에 따라
<b>지수 <span class="m">3/2</span>와 <span class="m">−1</span>을 더한다.</b></p>
<p class="m">2<sup>3/2</sup> × 2<sup>−1</sup> = 2<sup>3/2 + (−1)</sup> = 2<sup>3/2 − 2/2</sup> = 2<sup>1/2</sup></p>

<p><span class="step">④ 보기에서 찾는다.</span>
구한 값 <span class="m">2<sup>1/2</sup></span>은 보기 ④와 같다.</p>
<p class="m">답 ④</p>

## 노하우

지수 계산은 <b>밑을 소수(素數)로 통일</b>한 뒤 지수만 더하고 뺀다.
