## 문제

<p class="m">상수 a (a&gt;1)에 대하여 직선 y = 7이 두 곡선 y = 16a<sup>x</sup>, y = ¼a<sup>x</sup>과 만나는 점을 각각 A, B라 하자. AB = 4일 때, a의 값은?</p><div class="choices"><span>① √2</span><span>② 2</span><span>③ 2√2</span><span>④ 4</span><span>⑤ 4√2</span></div>

## 발상

두 점의 <span class='m'>y</span>좌표가 같으므로 AB는 순수하게 <span class='m'>x</span>좌표의 차이고, 그 차는 <b>진수의 비의 로그</b>가 된다.

## 풀이

<p><span class="step">① 선분 AB가 무엇인지 정확히 본다.</span>
두 점 A, B는 모두 직선 <span class="m">y = 7</span> 위에 있으므로
<b><span class="m">y</span>좌표가 <span class="m">7</span>로 같다.</b>
따라서 선분 AB의 길이는 순수하게 <b><span class="m">x</span>좌표의 차이</b>다.
그러니 두 점의 <span class="m">x</span>좌표를 각각 구해서 빼면 된다.</p>

<p><span class="step">② 점 A의 x좌표를 구한다.</span>
A는 <span class="m">y = 16a<sup>x</sup></span> 위의 점이고 <span class="m">y = 7</span>이므로</p>
<p class="m">16a<sup>x</sup> = 7</p>
<p>양변을 <span class="m">16</span>으로 나눈다.</p>
<p class="m">a<sup>x</sup> = 7/16</p>
<p><b>지수에 있는 <span class="m">x</span>를 끌어내리려면 로그를 쓴다.</b>
밑이 <span class="m">a</span>이므로 밑이 <span class="m">a</span>인 로그를 취한다.</p>
<p class="m">x<sub>A</sub> = log<sub>a</sub>(7/16)</p>

<p><span class="step">③ 점 B의 x좌표를 구한다.</span>
B는 <span class="m">y = ¼a<sup>x</sup></span> 위의 점이므로</p>
<p class="m">¼a<sup>x</sup> = 7</p>
<p>양변에 <span class="m">4</span>를 곱한다.</p>
<p class="m">a<sup>x</sup> = 28</p>
<p class="m">x<sub>B</sub> = log<sub>a</sub>28</p>

<p><span class="step">④ 두 x좌표의 차를 계산한다.</span>
<span class="m">a &gt; 1</span>이고 <span class="m">28 &gt; 7/16</span>이므로 <span class="m">x<sub>B</sub> &gt; x<sub>A</sub></span>이다.
로그의 뺄셈은 <b>진수의 나눗셈</b>이 된다.</p>
<p class="m">AB = x<sub>B</sub> − x<sub>A</sub> = log<sub>a</sub>28 − log<sub>a</sub>(7/16) = log<sub>a</sub>(28 ÷ 7/16)</p>
<p>나눗셈을 정리한다.</p>
<p class="m">28 ÷ 7/16 = 28 × 16/7 = 4 × 16 = 64</p>
<p class="m">AB = log<sub>a</sub>64</p>

<p><span class="step">⑤ 조건 AB = 4를 쓴다.</span></p>
<p class="m">log<sub>a</sub>64 = 4</p>
<p>로그의 정의에 따라 &lsquo;<span class="m">a</span>를 <span class="m">4</span>제곱하면 <span class="m">64</span>&rsquo;라는 뜻이다.</p>
<p class="m">a<sup>4</sup> = 64</p>

<p><span class="step">⑥ a를 구한다.</span>
<span class="m">64 = 2<sup>6</sup></span>이므로 양변의 밑을 <span class="m">2</span>로 맞춘다.</p>
<p class="m">a<sup>4</sup> = 2<sup>6</sup> → a = 2<sup>6/4</sup> = 2<sup>3/2</sup> = 2<sup>1</sup> × 2<sup>1/2</sup> = 2√2</p>
<p class="m">답 ③</p>

## 다른 풀이

<p><span class="step">두 곡선은 서로 평행이동한 것이다.</span> <span class="m">16a<sup>x</sup> = ¼·a<sup>x+k</sup></span>가 항상 성립하도록 <span class="m">k</span>를 잡으면</p>

<p class="m">16 = ¼·a<sup>k</sup> → a<sup>k</sup> = 64 → k = log<sub>a</sub>64</p>

<p>즉 <span class="m">y = ¼a<sup>x</sup></span>은 <span class="m">y = 16a<sup>x</sup></span>을 <b>오른쪽으로 log<sub>a</sub>64 만큼 민 것</b>이다. 두 곡선 사이의 <b>모든 수평선분의 길이가 이 값으로 일정</b>하므로, 직선이 <span class="m">y=7</span>이든 <span class="m">y=100</span>이든 상관없이</p>

<p class="m">AB = log<sub>a</sub>64 = 4 → a<sup>4</sup> = 64 → a = 2√2</p>

<p><b>7이라는 숫자를 아예 쓰지 않는다.</b> 본 풀이보다 한 단계 짧고, "직선을 <span class="m">y=k</span>로 바꾸면?" 같은 변형 발문에 즉답할 수 있다.</p>

## 노하우

지수함수를 수평선으로 자르면 <b>가로 길이 = log<sub>a</sub>(진수의 비)</b>. 두 로그를 따로 계산하지 말고 처음부터 비로 묶는다.
