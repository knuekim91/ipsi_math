## 문제

<p class="m">상수 a (a&gt;1)에 대하여 직선 y = 7이 두 곡선 y = 16a<sup>x</sup>, y = ¼a<sup>x</sup>과 만나는 점을 각각 A, B라 하자. AB = 4일 때, a의 값은?</p><div class="choices"><span>① √2</span><span>② 2</span><span>③ 2√2</span><span>④ 4</span><span>⑤ 4√2</span></div>

## 발상

두 점의 <span class='m'>y</span>좌표가 같으므로 AB는 순수하게 <span class='m'>x</span>좌표의 차이고, 그 차는 <b>진수의 비의 로그</b>가 된다.

## 풀이

<p class="m">16a<sup>x</sup> = 7 → x<sub>A</sub> = log<sub>a</sub>(7/16)</p><p class="m">¼a<sup>x</sup> = 7 → x<sub>B</sub> = log<sub>a</sub>28</p><p class="m">AB = log<sub>a</sub>(28 ÷ 7/16) = log<sub>a</sub>64 = 4</p><p class="m">a<sup>4</sup> = 64 = 2<sup>6</sup> → a = 2<sup>3/2</sup> = 2√2</p>

## 다른 풀이

<p><span class="step">두 곡선은 서로 평행이동한 것이다.</span> <span class="m">16a<sup>x</sup> = ¼·a<sup>x+k</sup></span>가 항상 성립하도록 <span class="m">k</span>를 잡으면</p>

<p class="m">16 = ¼·a<sup>k</sup> → a<sup>k</sup> = 64 → k = log<sub>a</sub>64</p>

<p>즉 <span class="m">y = ¼a<sup>x</sup></span>은 <span class="m">y = 16a<sup>x</sup></span>을 <b>오른쪽으로 log<sub>a</sub>64 만큼 민 것</b>이다. 두 곡선 사이의 <b>모든 수평선분의 길이가 이 값으로 일정</b>하므로, 직선이 <span class="m">y=7</span>이든 <span class="m">y=100</span>이든 상관없이</p>

<p class="m">AB = log<sub>a</sub>64 = 4 → a<sup>4</sup> = 64 → a = 2√2</p>

<p><b>7이라는 숫자를 아예 쓰지 않는다.</b> 본 풀이보다 한 단계 짧고, "직선을 <span class="m">y=k</span>로 바꾸면?" 같은 변형 발문에 즉답할 수 있다.</p>

## 노하우

지수함수를 수평선으로 자르면 <b>가로 길이 = log<sub>a</sub>(진수의 비)</b>. 두 로그를 따로 계산하지 말고 처음부터 비로 묶는다.
