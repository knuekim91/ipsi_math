## 문제

<p>상수 <span class="m">a</span> (<span class="m">a&gt;1</span>)과 직사각형 ABCD가 다음 조건을 만족시킨다.</p><span class="cond m">(가) 두 곡선 y = a<sup>x</sup>, y = 2x<sup>2</sup> − (7/2)x + 3은 모두 점 A와 점 B를 지난다.</span><span class="cond m">(나) 두 곡선 y = log<sub>a</sub>(x − ¼) − ¼, y = 2x<sup>2</sup> − (15/2)x + 15/2는 모두 점 C와 점 D를 지난다.</span><p><span class="m">a<sup>3</sup> = q/p</span>일 때 <span class="m">p+q</span>의 값을 구하시오. (<span class="m">p, q</span>는 서로소인 자연수)</p>

## 발상

<b>y = log<sub>a</sub>(x−¼) − ¼ 은 y = a<sup>x</sup>을 직선 y = x − ¼ 에 대칭이동한 곡선이다.</b> 직사각형도 이 직선에 대해 대칭이므로 변 AB의 기울기가 1로 고정된다.

## 풀이

<p><span class="step">① 두 로그·지수 곡선이 어떤 관계인지 밝힌다.</span>
직선 <span class="m">y = x + k</span>에 대한 대칭이동은 점 <span class="m">(x, y)</span>를
<span class="m">(y − k, x + k)</span>로 보낸다.
이 이동으로 <span class="m">y = a<sup>x</sup></span>은
<span class="m">y = log<sub>a</sub>(x + k) + k</span>가 된다.</p>
<p>(나)에 나온 곡선 <span class="m">y = log<sub>a</sub>(x − ¼) − ¼</span>과 비교하면</p>
<p class="m">k = −¼</p>
<p>즉 <b>두 곡선은 직선 <span class="m">y = x − ¼</span>에 대해 서로 대칭</b>이다.</p>

<p><span class="step">② 대칭이 직사각형에 무엇을 강제하는지 본다.</span>
A, B는 <span class="m">y = a<sup>x</sup></span> 위에 있고 D, C는 그 대칭 곡선 위에 있다.
대칭이동이 D를 A로, C를 B로 보내므로
<b>선분 AD는 대칭축에 수직</b>이다. 대칭축의 기울기가 <span class="m">1</span>이므로 AD의 기울기는 <span class="m">−1</span>이고,
직사각형에서 AB는 AD와 수직이므로</p>
<p class="m">AB의 기울기 = 1</p>

<p><span class="step">③ 기울기가 1인 현의 조건을 쓴다.</span>
A, B는 포물선 <span class="m">y = 2x<sup>2</sup> − (7/2)x + 3</span> 위에도 있다.
포물선 위 두 점을 잇는 현의 기울기는
<b>두 <span class="m">x</span>좌표의 합</b>으로 간단히 표현된다.</p>
<p class="m">기울기 = 2(x<sub>A</sub> + x<sub>B</sub>) − 7/2</p>
<p>이것이 <span class="m">1</span>이므로</p>
<p class="m">2(x<sub>A</sub> + x<sub>B</sub>) = 9/2 → x<sub>A</sub> + x<sub>B</sub> = 9/4</p>
<p>C, D도 마찬가지로 포물선 <span class="m">y = 2x<sup>2</sup> − (15/2)x + 15/2</span> 위에 있고
DC는 AB와 평행하므로 기울기가 <span class="m">1</span>이다.</p>
<p class="m">2(x<sub>C</sub> + x<sub>D</sub>) − 15/2 = 1 → x<sub>C</sub> + x<sub>D</sub> = 17/4</p>

<p><span class="step">④ 대칭으로 두 식을 잇는다.</span>
대칭이동 <span class="m">(x, y) ↦ (y + ¼, x − ¼)</span>이 A를 D로 보내므로</p>
<p class="m">x<sub>D</sub> = y<sub>A</sub> + ¼, &nbsp; x<sub>C</sub> = y<sub>B</sub> + ¼</p>
<p>이를 ③의 두 번째 식에 넣는다.</p>
<p class="m">(y<sub>A</sub> + ¼) + (y<sub>B</sub> + ¼) = 17/4</p>
<p class="m">y<sub>A</sub> + y<sub>B</sub> = 17/4 − ½ = 15/4</p>

<p><span class="step">⑤ 근과 계수의 관계로 x좌표를 구한다.</span>
A, B가 포물선 위의 점이므로</p>
<p class="m">y<sub>A</sub> + y<sub>B</sub> = 2(x<sub>A</sub><sup>2</sup> + x<sub>B</sub><sup>2</sup>) − (7/2)(x<sub>A</sub> + x<sub>B</sub>) + 6</p>
<p><span class="m">x<sub>A</sub><sup>2</sup> + x<sub>B</sub><sup>2</sup> = (x<sub>A</sub>+x<sub>B</sub>)<sup>2</sup> − 2x<sub>A</sub>x<sub>B</sub></span>를 쓰고
<span class="m">x<sub>A</sub>+x<sub>B</sub> = 9/4</span>를 넣으면</p>
<p class="m">y<sub>A</sub> + y<sub>B</sub> = 33/4 − 4x<sub>A</sub>x<sub>B</sub></p>
<p>이것이 <span class="m">15/4</span>이므로</p>
<p class="m">4x<sub>A</sub>x<sub>B</sub> = 33/4 − 15/4 = 18/4 → x<sub>A</sub>x<sub>B</sub> = 9/8</p>
<p>합과 곱을 알았으니 <span class="m">x<sub>A</sub>, x<sub>B</sub></span>는 다음 이차방정식의 두 근이다.</p>
<p class="m">t<sup>2</sup> − (9/4)t + 9/8 = 0 → 8t<sup>2</sup> − 18t + 9 = 0 → (4t − 3)(2t − 3) = 0</p>
<p class="m">x<sub>A</sub> = 3/4, &nbsp; x<sub>B</sub> = 3/2</p>

<p><span class="step">⑥ a를 구한다.</span>
A는 <span class="m">y = a<sup>x</sup></span> 위의 점이고, 포물선으로 <span class="m">y<sub>A</sub></span>를 계산하면</p>
<p class="m">y<sub>A</sub> = 2(3/4)<sup>2</sup> − (7/2)(3/4) + 3 = 9/8 − 21/8 + 24/8 = 12/8 = 3/2</p>
<p class="m">a<sup>3/4</sup> = 3/2</p>
<p>양변을 <span class="m">4</span>제곱한다.</p>
<p class="m">a<sup>3</sup> = (3/2)<sup>4</sup> = 81/16</p>

<p><span class="step">⑦ 답을 만든다.</span>
<span class="m">81</span>과 <span class="m">16</span>은 서로소이므로
<span class="m">q = 81</span>, <span class="m">p = 16</span>이다.</p>
<p class="m">p + q = 16 + 81 = 97</p>
<p>(네 꼭짓점은 <span class="m">A(3/4, 3/2)</span>, <span class="m">B(3/2, 9/4)</span>,
<span class="m">C(5/2, 5/4)</span>, <span class="m">D(7/4, 1/2)</span>로 실제로 직사각형을 이룬다.)</p>
<p class="m">답 97</p>

## 노하우

<b>log<sub>a</sub>(x+k)+k 꼴을 보면 즉시 &lsquo;y=a<sup>x</sup>을 y=x+k에 대칭시킨 것&rsquo;으로 읽는다.</b> 대칭이 만드는 기울기 ±1을 찾으면, 포물선의 현은 <b>두 근의 합</b>으로 즉시 결정된다.
