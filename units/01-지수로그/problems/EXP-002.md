## 문제

<p class="m">방정식 log<sub>3</sub>(x−3) = log<sub>9</sub>(2x−3)을 만족시키는 실수 x의 값을 구하시오.</p>

## 발상

log<sub>9</sub> = ½log<sub>3</sub>로 밑을 맞추고, <b>마지막에 반드시 진수 조건으로 거른다.</b> 무연근이 하나 나오도록 설계된 문제다.

## 풀이

<p><span class="step">① 밑이 다르다는 것을 먼저 본다.</span>
왼쪽은 밑이 <span class="m">3</span>, 오른쪽은 밑이 <span class="m">9</span>다.
<span class="m">9 = 3<sup>2</sup></span>이므로 밑변환 공식으로 오른쪽을 밑 <span class="m">3</span>으로 바꾼다.</p>
<p class="m">log<sub>9</sub>(2x−3) = (1/2)log<sub>3</sub>(2x−3)</p>
<p>따라서 방정식은 다음과 같아진다.</p>
<p class="m">log<sub>3</sub>(x−3) = (1/2)log<sub>3</sub>(2x−3)</p>

<p><span class="step">② 계수를 없애고 진수끼리 비교한다.</span>
양변에 <span class="m">2</span>를 곱한다.</p>
<p class="m">2log<sub>3</sub>(x−3) = log<sub>3</sub>(2x−3)</p>
<p>왼쪽의 <span class="m">2</span>를 지수로 올린다.</p>
<p class="m">log<sub>3</sub>(x−3)<sup>2</sup> = log<sub>3</sub>(2x−3)</p>
<p>밑이 같은 로그가 같으면 <b>진수도 같다.</b></p>
<p class="m">(x − 3)<sup>2</sup> = 2x − 3</p>

<p><span class="step">③ 이차방정식을 푼다.</span>
왼쪽을 전개한다.</p>
<p class="m">x<sup>2</sup> − 6x + 9 = 2x − 3</p>
<p>오른쪽 항을 왼쪽으로 넘긴다.</p>
<p class="m">x<sup>2</sup> − 6x − 2x + 9 + 3 = 0</p>
<p class="m">x<sup>2</sup> − 8x + 12 = 0</p>
<p class="m">(x − 2)(x − 6) = 0 → x = 2 또는 x = 6</p>

<p><span class="step">④ 진수 조건으로 거른다.</span>
<b>로그의 진수는 항상 양수여야 한다.</b> 원래 식의 진수는
<span class="m">x − 3</span>과 <span class="m">2x − 3</span>이다.</p>
<p class="m">x − 3 &gt; 0 → x &gt; 3</p>
<p><span class="m">x = 2</span>는 <span class="m">x − 3 = −1 &lt; 0</span>이라
원래 식에 넣을 수조차 없다. <b>버린다.</b></p>
<p class="m">x = 6</p>
<p class="m">답 6</p>

## 함정

<span class='m'>x=2</span>를 원식에 넣으면 <span class='m'>log<sub>3</sub>(−1)</span>. 제곱하는 순간 정보가 사라지므로 검산은 필수다.

## 노하우

로그방정식은 <b>① 밑 통일 → ② 진수 비교 → ③ 진수&gt;0 검산</b>의 3단계. 3단계를 빠뜨리면 답이 두 개가 된다.
