## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4, 5}</span>에 대하여 다음 조건을 만족시키는 함수 <span class="m">f : X → X</span>의 개수를 구하시오.</p>
<span class="cond m">(가) f(1)f(5) = 4</span>
<span class="cond m">(나) Σ<sub>k=1</sub><sup>4</sup> |f(k+1) − f(k)| = 3</span>

## 발상

(가)가 이번엔 <b>세 경우</b>를 준다. 그런데 <b><span class="m">Σ|a<sub>k</sub>| − |Σa<sub>k</sub>|</span>는 되돌아간 거리의 2배라 항상 짝수</b>다. 이 홀짝만으로 한 경우가 통째로 사라진다.

## 풀이

<p><span class="step">① 조건 (가).</span> <span class="m">(f(1), f(5)) = (1, 4), (4, 1), (2, 2)</span></p>

<p><span class="step">② 홀짝으로 거르기.</span> <span class="m">Σ|a<sub>k</sub>| = 3</span>이고</p>
<p class="m">Σ|a<sub>k</sub>| − |Σa<sub>k</sub>| = 2 × (되돌아간 거리) → 항상 짝수</p>
<p>· <span class="m">(2, 2)</span> : <span class="m">|Σa<sub>k</sub>| = 0</span> → <span class="m">3 − 0 = 3</span> (홀수) → <b>불가능</b></p>
<p>· <span class="m">(1, 4)</span>, <span class="m">(4, 1)</span> : <span class="m">|Σa<sub>k</sub>| = 3</span> → <span class="m">3 − 3 = 0</span> (짝수) → 가능</p>

<p><span class="step">③ 남은 두 경우.</span> <span class="m">|Σa<sub>k</sub>| = 3 = Σ|a<sub>k</sub>|</span>이므로 단조가 강제된다. 양 끝이 1과 4이므로 가운데 <span class="m">f(2), f(3), f(4)</span>는 <b>1과 4 사이</b>의 값만 가질 수 있고, 그 안에서 단조:</p>
<p class="m"><sub>4</sub>H<sub>3</sub> = <sub>6</sub>C<sub>3</sub> = 20</p>
<p><span class="step">④</span> <span class="m">20 × 2 = 40</span></p>

## 함정

<span class="m">(2, 2)</span>를 "0에서 출발해 0으로 돌아오니 되겠지" 하고 세기 시작하면 시간을 크게 잃는다. <b>홀짝을 먼저 보면 3초 만에 지워진다.</b> 또 <span class="m">(1, 4)</span>에서 가운데 값이 5가 될 수 없다는 점(단조라서 4를 넘을 수 없다)도 놓치기 쉽다.

## 노하우

<b>계차 문제에서 경우가 여러 개로 갈리면, 세기 전에 <span class="m">Σ|a| − |Σa|</span>의 홀짝부터 확인한다.</b> 이 값은 되돌아간 거리의 2배이므로 홀수가 나오면 그 경우는 존재하지 않는다. 계산 없이 가지치기가 된다.
