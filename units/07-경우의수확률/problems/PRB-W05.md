## 문제

<p>빨간색 카드 1장, 주황색 카드 1장, 노란색 카드 1장, 파란색 카드 1장,
보라색 카드 7장이 있다. 이 11장의 카드를 세 학생 A, B, C에게 다음 규칙에 따라
남김없이 나누어 주는 경우의 수를 구하시오. (단, 같은 색 카드끼리는 서로 구별하지 않는다.)</p>

<div class="cond">
<span class="cond m">세 학생 A, B, C가 받는 카드의 색의 가짓수는 모두 홀수이다.</span>
</div>

## 발상

<b>학생이 받는 색의 가짓수만 보면 된다. 카드 장수는 조건이 아니다.</b><br><br>

<b>색 네 종류를 나누어 보면 성질이 다르다.</b>
빨강, 주황, 노랑, 파랑은 <b>한 장뿐이라 어느 한 학생에게 간다.</b>
보라는 <b>몇 장을 받았는지가 아니라 받았는지 안 받았는지</b>만 색의 가짓수에 영향을 준다.
학생이 보라를 1장이든 5장이든 받으면 색은 한 가지 더 늘 뿐이다.<br><br>

<b>그러므로 두 단계로 나눈다.</b>
① 단색 카드 4장을 세 학생에게 나눈다 (서로 다른 색이므로 순서가 중요하다).
② 보라를 받은 학생 집합을 정하고, 보라 7장을 그 학생들에게 1장 이상씩 나눈다.
같은 색끼리 구별하지 않으므로 이 나눔은 <b>자리를 고르는 조합</b>으로 센다.

## 풀이

<p><span class="step">① 학생이 받는 색의 가짓수를 식으로 쓴다.</span>
학생 i가 받은 단색 카드 수를 <span class="m">k<sub>i</sub></span>,
보라를 1장 이상 받았으면 <span class="m">e<sub>i</sub> = 1</span>, 아니면 <span class="m">0</span>이라 하자.
그러면 색의 가짓수는</p>
<p class="m">(색의 가짓수)<sub>i</sub> = k<sub>i</sub> + e<sub>i</sub></p>
<p>이고, 이 값이 모두 홀수이어야 한다.
<span class="m">k<sub>1</sub> + k<sub>2</sub> + k<sub>3</sub> = 4</span>이다.</p>

<p><span class="step">② 단색 카드의 배분 수를 센다.</span>
네 색이 서로 다르므로 <span class="m">(k<sub>1</sub>, k<sub>2</sub>, k<sub>3</sub>)</span>인 배분은</p>
<p class="m">4! / (k<sub>1</sub>! k<sub>2</sub>! k<sub>3</sub>!)</p>
<p>가지다.</p>

<p><span class="step">③ 단색 카드 배분 (k₁, k₂, k₃)에서 보라를 받을 학생이 정해진다.</span>
<span class="m">k<sub>i</sub> + e<sub>i</sub></span>가 홀수이므로 <b><span class="m">k<sub>i</sub></span>가 짝수이면 <span class="m">e<sub>i</sub> = 1</span>, 홀수이면 <span class="m">e<sub>i</sub> = 0</span></b>이다.
즉 보라를 받는 학생 집합 <span class="m">S</span>는 <span class="m">k<sub>i</sub></span>가 짝수인 학생들이다.
세 수의 합이 <span class="m">4</span>(짝수)이므로 세 수가 모두 홀수일 수는 없고, 따라서 <span class="m">S</span>는 공집합이 아니다.</p>

<p><span class="step">④ 보라 7장을 S에 1장 이상씩 나눈다.</span>
<span class="m">|S| = s</span>이면 보라 7장을 <span class="m">s</span>명에게 1장 이상씩 나누는 방법은</p>
<p class="m">C(6, s − 1)</p>
<p>이다. 보라는 같은 색이므로 순서를 세지 않는다.</p>

<p><span class="step">⑤ 단색 카드 배분의 종류를 나열한다.</span>
세 학생이 받은 단색 카드 수 <span class="m">(k<sub>1</sub>, k<sub>2</sub>, k<sub>3</sub>)</span>의 종류는 네 가지다.</p>
<p class="m">(4, 0, 0) : 짝수 셋 → s = 3 → C(6,2) = 15, 배분 1가지, 순서 3가지 → 45</p>
<p class="m">(3, 1, 0) : 짝수 하나 → s = 1 → C(6,0) = 1, 배분 4가지, 순서 6가지 → 24</p>
<p class="m">(2, 1, 1) : 짝수 하나 → s = 1 → C(6,0) = 1, 배분 12가지, 순서 3가지 → 36</p>
<p class="m">(2, 2, 0) : 짝수 셋 → s = 3 → C(6,2) = 15, 배분 6가지, 순서 3가지 → 270</p>
<p>여기서 배분 가짓수는 단색 4장을 나누는 <span class="m">4!/(k<sub>1</sub>!k<sub>2</sub>!k<sub>3</sub>!)</span>이다.
순서 가짓수는 <span class="m">(k<sub>1</sub>, k<sub>2</sub>, k<sub>3</sub>)</span>의 자리 바꿈이다.</p>

<p><span class="step">⑥ 색의 가짓수 조합으로 확인한다.</span>
<b>(3, 1, 0)과 (2, 1, 1)은 색의 가짓수가 모두 (1, 1, 3)의 배열이므로 합치면 60</b>이다.
(4, 0, 0)은 (1, 1, 5), (2, 2, 0)은 (1, 3, 3)이다.
그래서 색의 가짓수 조합별로는 <span class="m">(1, 1, 3) : 60</span>, <span class="m">(1, 1, 5) : 45</span>, <span class="m">(1, 3, 3) : 270</span>이다.</p>

<p><span class="step">⑦ 답을 만든다.</span></p>
<p class="m">60 + 45 + 270 = 375</p>
<p class="m">답 375</p>

<p><span class="step">⑧ 확인한다.</span>
세 학생에게 카드를 나누는 방법을 전부 세어(<span class="m">3<sup>4</sup></span>가지 단색 배분 × 보라 분배)
같은 값 375가 나온다. ✓</p>

## 다른 풀이

<b>전체를 직접 세는 방법도 있다.</b>
단색 카드 4장의 배분 <span class="m">3<sup>4</sup> = 81</span>가지 각각에 대하여,
보라 7장의 분배 가운데 색 가짓수가 홀수가 되는 것만 센다.
보라의 분배는 <span class="m">C(9, 2) = 36</span>가지이므로 손으로 다 세기는 힘들다.
그래서 <b>보라를 &lsquo;받았는가&rsquo;로 줄이는 앞의 방법</b>이 훨씬 빠르다.

## 함정

<b>(1, 3, 3)을 210으로 세면 틀린다.</b>
손풀이에서 (1, 3, 3) 계열을 210가지로 적었다.
실제로는 <b>순서가 세 가지이고 각 순서가 90가지</b>이므로 270가지다.
<span class="m">60 + 45 + 210 = 315</span>가 되면 한 계열을 빠뜨린 것이다.<br><br>

<b>보라를 몇 장 받았는지를 색의 가짓수에 더하면 안 된다.</b>
보라 7장을 한 학생이 다 받아도 색은 1가지다.
<span class="m">보라 장수</span>가 아니라 <span class="m">받았는지 여부</span>만 가짓수에 들어간다.<br><br>

<b>보라를 받은 학생이 최소 한 명은 있어야 한다.</b>
보라 7장을 남김없이 나누어야 하므로 <span class="m">S = ∅</span>인 경우는 없다.
보라를 받을 학생이 없으면 보라 7장을 나눌 방법이 없으므로 그 경우는 <span class="m">0</span>가지로 센다.

## 노하우

<b>&lsquo;가짓수&rsquo; 조건은 &lsquo;개수 + 있는지 여부&rsquo;로 쪼갠다.</b></p>
<p class="m">(색의 가짓수) = (한 장뿐인 색의 수) + [많은 색이 하나라도 있는가]</p>
<p><b>여러 장인 색은 &lsquo;있다/없다&rsquo;의 0 또는 1로만 센다.</b>
이 한 줄이 이 문항 전체를 열어 준다.<br><br>

<b>같은 색을 여러 학생에게 나누는 문제는 자리를 고르는 조합이다.</b></p>
<p class="m">m 장을 s 명에게 1장 이상씩 나누는 방법 = C(m − 1, s − 1)</p>
<p>이 공식은 중복조합의 칸막이와 같다. 보라 7장을 칸막이 6개 가운데 고른다고 생각하면 된다.
