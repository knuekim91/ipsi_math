## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4}</span>에 대하여 <span class="m">f(1) = 1</span>, <span class="m">f(4) = 4</span>인 함수 <span class="m">f : X → X</span> 중 다음을 만족시키는 것의 개수를 구하시오.</p>
<span class="cond m">Σ<sub>k=1</sub><sup>3</sup> |f(k+1) − f(k)| = 5</span>

## 발상

이번엔 두 값이 <b>다르다</b>. 순변위는 3인데 총 이동 거리는 5. <b>남는 2는 어디에 쓰였는가?</b> 되돌아갔다가 다시 오는 데 쓰였고, 되돌아간 거리 1칸마다 총 이동 거리는 <b>2씩</b> 늘어난다.

## 풀이

<p><span class="step">① 남는 거리를 계산한다.</span></p>
<p class="m">5 − 3 = 2 = 2 × (되돌아간 거리) → 되돌아간 거리 = 1</p>
<p>즉 <b>정확히 한 번, 1만큼만 뒤로 간다.</b></p>

<p><span class="step">② 세 걸음을 나열한다.</span> 걸음 <span class="m">a<sub>1</sub>, a<sub>2</sub>, a<sub>3</sub></span>의 합은 3, 절댓값 합은 5, 음수 걸음의 크기 합은 1. 따라서 음수 걸음은 <span class="m">−1</span> 하나뿐이고 나머지 두 걸음의 합은 4.</p>

<p><span class="step">③ 함숫값이 X를 벗어나지 않게 확인하며 적는다.</span></p>
<p class="m">(1, 2, 1, 4) : 걸음 +1, −1, +3</p>
<p class="m">(1, 3, 2, 4) : 걸음 +2, −1, +2</p>
<p class="m">(1, 4, 3, 4) : 걸음 +3, −1, +1</p>
<p>모두 <b>가운데에서 한 번 내려갔다 다시 올라간다.</b> 답은 <span class="m">3</span>.</p>

## 함정

되돌아간 거리를 <span class="m">5 − 3 = 2</span>로 착각하기 쉽다. <b>되돌아가면 그만큼 다시 와야 하므로 두 번 계산된다.</b> 그래서 2로 나눈 1이 답이다.

## 노하우

<b>Σ|차| − |Σ차| = 2 × (되돌아간 거리).</b> 여기서 두 가지가 따라 나온다.
① 이 값이 <b>0이면 단조</b>(사다리 2·3단).
② 이 값은 <b>언제나 짝수</b>이므로, 홀수가 나오는 경우는 <b>아예 존재하지 않는다</b>. 실제로 <span class="m">f(1)=1, f(4)=4</span>에서 가능한 합은 3, 5, 7, 9로 모두 홀수다. 이 홀짝 판별만으로 경우를 통째로 지울 수 있다.
