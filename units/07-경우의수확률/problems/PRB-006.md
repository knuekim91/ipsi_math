## 문제

<p>다음 조건을 만족시키는 자연수 <span class="m">a, b, c, d</span>의 모든 순서쌍 <span class="m">(a, b, c, d)</span>의 개수를 구하시오.</p><span class="cond m">(가) a + b + c + d = 14</span><span class="cond m">(나) 10a ≥ d 이고 c &lt; d<sup>2</sup>이다.</span>

## 발상

두 부등식을 직접 만족시키려 하지 말고 <b>위반하는 경우를 센다.</b> 10a &lt; d 는 d ≥ 11이 필요하고, c ≥ d<sup>2</sup>은 d ≤ 3에서만 가능하다.

## 풀이

<p><span class="step">① 부등식을 직접 만족시키려 하지 않는다.</span>
조건 (나)는 <span class="m">10a ≥ d</span>와 <span class="m">c &lt; d<sup>2</sup></span> 두 개다.
이 둘을 <b>동시에 만족시키는 것을 세는 것보다,
어기는 것을 세서 전체에서 빼는 편이 훨씬 짧다.</b>
어기는 경우가 매우 드물기 때문이다.</p>

<p><span class="step">② 전체를 센다.</span>
자연수 <span class="m">a, b, c, d</span>의 합이 <span class="m">14</span>인 순서쌍의 개수는
칸막이 방법으로 구한다. <span class="m">14</span>개를 늘어놓고
사이의 <span class="m">13</span>개 틈에 칸막이 <span class="m">3</span>개를 넣는다.</p>
<p class="m"><sub>13</sub>C<sub>3</sub> = 286</p>

<p><span class="step">③ 첫 번째 조건을 어기는 경우를 센다.</span>
<span class="m">10a &lt; d</span>인 경우다.
<span class="m">a</span>는 자연수라 <span class="m">a ≥ 1</span>이므로 <span class="m">10a ≥ 10</span>이고,
따라서 <span class="m">d ≥ 11</span>이어야 한다.
그런데 나머지 셋도 자연수라 최소 <span class="m">1</span>씩은 필요하다.</p>
<p class="m">1 + 1 + 1 + 11 = 14</p>
<p>합이 딱 맞아떨어지므로 <b>이 한 가지밖에 없다.</b></p>
<p class="m">(a, b, c, d) = (1, 1, 1, 11) → 1개</p>

<p><span class="step">④ 두 번째 조건을 어기는 경우를 센다.</span>
<span class="m">c ≥ d<sup>2</sup></span>인 경우다.
<span class="m">d</span>가 커지면 <span class="m">d<sup>2</sup></span>이 급히 커져 금방 불가능해지므로
<span class="m">d</span>를 작은 값부터 하나씩 본다.</p>

<p><b><span class="m">d = 1</span></b> : <span class="m">c ≥ 1</span>인데 자연수라 <b>항상 성립</b>한다.
남은 <span class="m">a + b + c = 13</span>의 자연수해를 모두 센다.</p>
<p class="m"><sub>12</sub>C<sub>2</sub> = 66</p>

<p><b><span class="m">d = 2</span></b> : <span class="m">c ≥ 4</span>이고 <span class="m">a + b + c = 12</span>.
<span class="m">c′ = c − 3</span>으로 바꾸면 <span class="m">c′ ≥ 1</span>이고 <span class="m">a + b + c′ = 9</span>.</p>
<p class="m"><sub>8</sub>C<sub>2</sub> = 28</p>

<p><b><span class="m">d = 3</span></b> : <span class="m">c ≥ 9</span>이고 <span class="m">a + b + c = 11</span>.
<span class="m">c′ = c − 8</span>로 바꾸면 <span class="m">a + b + c′ = 3</span>.</p>
<p class="m"><sub>2</sub>C<sub>2</sub> = 1</p>

<p><b><span class="m">d ≥ 4</span></b> : <span class="m">c ≥ 16</span>인데 남은 합이 <span class="m">10</span> 이하라 <b>불가능</b>하다.</p>
<p class="m">66 + 28 + 1 = 95</p>

<p><span class="step">⑤ 두 위반이 겹치는지 확인한다.</span>
③에서 나온 <span class="m">(1, 1, 1, 11)</span>은 <span class="m">c = 1</span>,
<span class="m">d<sup>2</sup> = 121</span>이라 <span class="m">c &lt; d<sup>2</sup></span>이다.
즉 두 번째 조건은 어기지 않는다. <b>겹침은 0</b>이다.</p>

<p><span class="step">⑥ 빼서 답을 만든다.</span></p>
<p class="m">286 − 1 − 95 = 190</p>
<p class="m">답 190</p>

## 노하우

<b>부등식이 붙은 방정식의 해 개수는 &lsquo;전체 − 위반&rsquo;이 거의 항상 빠르다.</b> c ≥ 4 같은 하한은 <span class='m'>c′ = c−3</span> 치환으로 표준 중복조합으로 되돌린다. 마지막에 <b>두 위반이 겹치는지</b> 반드시 확인한다.
