## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4, 5, 6, 7}</span>에 대하여 다음 조건을 만족시키는 함수 <span class="m">f : X → X</span>의 개수를 구하시오.</p>
<span class="cond m">(가) f(1)f(7) = 7</span>
<span class="cond m">(나) Σ<sub>k=1</sub><sup>6</sup> |f(k+1) − f(k)| = 6</span>

## 발상

7이 <b>소수</b>라는 점이 (가)를 두 경우로 좁힌다. 그 뒤는 원문항과 똑같이 <b><span class="m">|Σa<sub>k</sub>| = Σ|a<sub>k</sub>| = 6</span> → 단조</b>.

## 풀이

<p><span class="step">①</span> 7은 소수이므로 <span class="m">(f(1), f(7)) = (1, 7)</span> 또는 <span class="m">(7, 1)</span>.</p>
<p><span class="step">②</span> <span class="m">a<sub>k</sub> = f(k+1) − f(k)</span>라 하면 <span class="m">Σa<sub>k</sub> = f(7) − f(1) = ±6</span>이고 <span class="m">Σ|a<sub>k</sub>| = 6</span>이므로</p>
<p class="m">|Σa<sub>k</sub>| = 6 = Σ|a<sub>k</sub>|</p>
<p>따라서 모든 <span class="m">a<sub>k</sub></span>의 부호가 같고, <span class="m">f</span>는 단조다.</p>
<p><span class="step">③</span> 양 끝이 1과 7로 고정되므로 가운데 <span class="m">f(2), …, f(6)</span> 다섯 개를 단조로 고르는 중복조합:</p>
<p class="m"><sub>7</sub>H<sub>5</sub> = <sub>11</sub>C<sub>5</sub> = 462</p>
<p><span class="step">④</span> <span class="m">462 × 2 = 924</span></p>

## 노하우

<b>집합이 커져도 절차는 그대로다: 소수로 끝점 고정 → 절댓값 합과 순변위 비교 → 단조 → 중복조합.</b> <span class="m"><sub>n</sub>H<sub>r</sub> = <sub>n+r−1</sub>C<sub>r</sub></span>에서 <b>n은 함숫값의 가짓수, r은 정해야 할 가운데 항의 개수</b>임을 헷갈리지 말 것.
