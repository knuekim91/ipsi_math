## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4, 5}</span>와 <span class="m">f(1) = 2</span>, <span class="m">f(5) = 5</span>를 만족시키는 함수 <span class="m">f : X → X</span>에 대하여</p>
<p class="m">Σ<sub>k=1</sub><sup>4</sup> |f(k+1) − f(k)|</p>
<p>의 최솟값을 <span class="m">m</span>, 최솟값을 갖게 하는 함수 <span class="m">f</span>의 개수를 <span class="m">N</span>이라 하자. <span class="m">m + N</span>의 값을 구하시오.</p>

## 발상

원문항이 "합이 이 값일 때 단조"였다면, 이번엔 <b>거꾸로 "언제 합이 가장 작은가"</b>를 묻는다. 답은 같은 부등식에서 나온다 — <b>총 이동거리는 순변위보다 작을 수 없고, 같아지는 때가 곧 단조</b>다.

## 풀이

<p><span class="step">① 최솟값.</span> <span class="m">a<sub>k</sub> = f(k+1) − f(k)</span>라 하면 삼각부등식에서</p>
<p class="m">Σ|a<sub>k</sub>| ≥ |Σa<sub>k</sub>| = |f(5) − f(1)| = |5 − 2| = 3</p>
<p>그러므로 <span class="m">m = 3</span>이고, 등호는 모든 <span class="m">a<sub>k</sub></span>의 부호가 같을 때 — 여기서는 합이 양수이므로 <b>단조증가</b>일 때다.</p>

<p><span class="step">② 그때의 개수.</span> <span class="m">2 = f(1) ≤ f(2) ≤ f(3) ≤ f(4) ≤ f(5) = 5</span>이므로 가운데 세 값은 <span class="m">{2, 3, 4, 5}</span>에서 단조로 고른다:</p>
<p class="m">N = <sub>4</sub>H<sub>3</sub> = <sub>6</sub>C<sub>3</sub> = 20</p>

<p><span class="step">③</span> <span class="m">m + N = 3 + 20 = 23</span></p>

## 함정

가운데 값의 범위를 <span class="m">X</span> 전체인 <span class="m">{1, …, 5}</span>로 잡으면 안 된다. <b>단조증가이고 양 끝이 2와 5이므로 2 미만은 불가능</b>하다. 범위를 <span class="m">{2, 3, 4, 5}</span>로 좁히는 것이 이 문제의 계산 핵심이다.

## 노하우

<b>"절댓값 합의 최솟값"을 묻는 문제는 곧 <span class="m">|순변위|</span>를 묻는 것이고, 최솟값을 주는 함수는 언제나 단조다.</b> 같은 부등식을 정방향(합이 주어짐 → 단조)과 역방향(최솟값을 물음 → 단조)으로 모두 쓸 수 있어야 한다. 그리고 단조가 확정되면 <b>가운데 값의 범위가 두 끝값 사이로 좁아진다</b>는 것을 반드시 반영한다.
