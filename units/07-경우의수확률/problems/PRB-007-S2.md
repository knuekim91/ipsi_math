## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4}</span>에 대하여 <span class="m">f(1) = 1</span>, <span class="m">f(4) = 4</span>인 함수 <span class="m">f : X → X</span> 중 다음을 만족시키는 것의 개수를 구하시오.</p>
<span class="cond m">Σ<sub>k=1</sub><sup>3</sup> |f(k+1) − f(k)| = 3</span>

## 발상

1단에서 <b>차의 합은 <span class="m">f(4) − f(1) = 3</span></b>임을 안다. 그런데 <b>절댓값을 씌운 합도 3</b>이다. <b>거리를 3만큼 움직여서 3만큼 이동했다면, 되돌아간 적이 한 번도 없다.</b>

## 풀이

<p><span class="step">① 두 값을 나란히 놓는다.</span></p>
<p class="m">Σ(f(k+1) − f(k)) = 4 − 1 = 3 &nbsp;(순변위)</p>
<p class="m">Σ|f(k+1) − f(k)| = 3 &nbsp;(총 이동 거리)</p>

<p><span class="step">② 같으므로 방향 전환이 없다.</span> 즉 <span class="m">f(k+1) ≥ f(k)</span>이고</p>
<p class="m">1 = f(1) ≤ f(2) ≤ f(3) ≤ f(4) = 4</p>

<p><span class="step">③ 가운데 두 값을 고른다.</span> <span class="m">f(2) ≤ f(3)</span>를 <span class="m">{1, 2, 3, 4}</span>에서:</p>
<p class="m"><sub>4</sub>H<sub>2</sub> = <sub>5</sub>C<sub>2</sub> = 10</p>

<p><span class="step">④ 손으로 확인해 보기.</span> 답이 10개뿐이니 전부 적어 볼 수 있다.</p>
<p class="m">(1,1,1,4) (1,1,2,4) (1,1,3,4) (1,1,4,4) (1,2,2,4)<br>(1,2,3,4) (1,2,4,4) (1,3,3,4) (1,3,4,4) (1,4,4,4)</p>
<p><b>전부 증가만 한다.</b> 규칙이 맞는지 눈으로 확인하고 넘어가는 것이 이 단계의 목적이다.</p>

## 노하우

<b>순변위와 총 이동거리를 <u>두 줄로 나란히 써 보는 습관</u>을 들인다.</b> 두 값이 같으면 단조, 다르면 되돌아간 것이다. 이 비교가 이 유형의 출발점이다.
