## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4}</span>에 대하여 <span class="m">f(1) = 4</span>, <span class="m">f(4) = 1</span>인 함수 <span class="m">f : X → X</span> 중 다음을 만족시키는 것의 개수를 구하시오.</p>
<span class="cond m">Σ<sub>k=1</sub><sup>3</sup> |f(k+1) − f(k)| = 5</span>

## 발상

4단과 <b>방향만 반대</b>다. 순변위가 <span class="m">−3</span>인데 총 이동 거리가 5이므로 남는 2는 되돌아가는 데 쓰였다. 다만 <b>이번엔 되돌아감이 &lsquo;위로&rsquo;</b>이고, <span class="m">X</span>의 위쪽 끝이 4라서 <b>올라갈 수 있는 자리가 거의 없다.</b> 이 제약이 답을 세 개로 좁힌다.

## 풀이

<p><span class="step">① 되돌아간 거리.</span></p>
<p class="m">|순변위| = |1 − 4| = 3, &nbsp; 총 이동 거리 = 5</p>
<p class="m">5 − 3 = 2 = 2 × (되돌아간 거리) → 되돌아간 거리 = 1</p>
<p>진행 방향이 아래쪽이므로 <b>위로 올라가는 걸음이 정확히 한 번, 그 크기는 1</b>이다.</p>

<p><span class="step">② 어느 걸음이 올라갈 수 있는가.</span> 세 걸음을 <span class="m">a<sub>1</sub>, a<sub>2</sub>, a<sub>3</sub></span>이라 하면</p>
<p class="m">a<sub>1</sub> = f(2) − 4 ≤ 0 &nbsp;(f(2) ≤ 4이므로 올라갈 수 없다)</p>
<p class="m">a<sub>3</sub> = 1 − f(3) ≤ 0 &nbsp;(f(3) ≥ 1이므로 올라갈 수 없다)</p>
<p>따라서 <b>올라가는 걸음은 가운데 <span class="m">a<sub>2</sub></span>일 수밖에 없다.</b></p>

<p class="m">a<sub>2</sub> = +1 → f(3) = f(2) + 1</p>

<p><span class="step">③ 남은 조건을 확인한다.</span> <span class="m">f(3) = f(2) + 1</span>이면 총 이동 거리는</p>
<p class="m">(4 − f(2)) + 1 + (f(2) + 1 − 1) = 5</p>
<p>로 <span class="m">f(2)</span>와 무관하게 <b>항상 5</b>다. 그러니 범위 조건만 보면 된다.</p>

<p><span class="step">④ 개수.</span> <span class="m">f(2)</span>와 <span class="m">f(3) = f(2)+1</span>이 모두 <span class="m">X</span>에 있어야 하므로 <span class="m">f(2) = 1, 2, 3</span>.</p>
<p class="m">(4, 1, 2, 1), &nbsp; (4, 2, 3, 1), &nbsp; (4, 3, 4, 1) → 3개</p>

## 함정

4단처럼 "걸음의 부호 배열을 모두 세어 보자"고 시작하면 경우가 열댓 개로 불어난다.
<b>먼저 &lsquo;어느 걸음이 올라갈 수 있는가&rsquo;를 따지면 자리가 하나로 못 박힌다.</b>
양 끝값이 <span class="m">X</span>의 최대·최소에 붙어 있을 때는 <b>첫 걸음과 마지막 걸음의 방향이 강제된다</b>는 것을 놓치지 말 것.

## 노하우

<b>되돌아가는 걸음은 &lsquo;어디서&rsquo; 일어날 수 있는지부터 묻는다.</b>
진행 방향이 아래면 되돌아감은 위로인데, 출발점이 이미 최대값이면 첫 걸음은 올라갈 수 없다.
같은 이유로 도착점이 최소값이면 마지막 걸음도 올라갈 수 없다.
<b>양 끝이 막히면 되돌아감은 가운데에서만 일어난다</b> — 이 한 줄로 경우의 수가 한 자리로 줄어든다.
