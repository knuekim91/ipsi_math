## 문제

<p class="m">한 개의 주사위를 두 번 던져 나오는 눈의 수를 차례로 a, b라 하자. a가 3 이하이거나 a×b가 8의 배수일 확률은?</p><div class="choices"><span>① 5/9</span><span>② 11/18</span><span>③ 2/3</span><span>④ 13/18</span><span>⑤ 7/9</span></div>

## 발상

&lsquo;또는&rsquo;은 포함배제. 두 번째 사건은 개수가 적으니 a별로 b를 센다.

## 풀이

<p><span class="step">① &lsquo;또는&rsquo;이므로 포함배제를 준비한다.</span>
두 사건을 다음과 같이 부르자.</p>
<p class="m">사건 P : a ≤ 3 &nbsp;/&nbsp; 사건 Q : a × b가 8의 배수</p>
<p>&lsquo;P 또는 Q&rsquo;의 경우의 수는 <b>겹치는 부분을 한 번 빼야</b> 한다.</p>
<p class="m">n(P ∪ Q) = n(P) + n(Q) − n(P ∩ Q)</p>
<p>전체 경우의 수는 <span class="m">6 × 6 = 36</span>이다.</p>

<p><span class="step">② n(P)를 센다.</span>
<span class="m">a</span>가 <span class="m">1, 2, 3</span> 중 하나이고 <span class="m">b</span>는 무엇이든 좋다.</p>
<p class="m">n(P) = 3 × 6 = 18</p>

<p><span class="step">③ n(Q)를 a별로 센다.</span>
<span class="m">ab</span>가 <span class="m">8 = 2<sup>3</sup></span>의 배수가 되려면
<span class="m">a</span>와 <span class="m">b</span>가 가진 <b>인수 2가 합쳐서 세 개 이상</b>이어야 한다.
<span class="m">a</span>를 하나씩 놓고 확인한다.</p>
<p class="m">a = 1 (2가 없음) : b가 8의 배수여야 하는데 6 이하에는 없다 → 0개</p>
<p class="m">a = 2 (2가 하나) : b가 4의 배수 → b = 4 → 1개</p>
<p class="m">a = 3 (2가 없음) : 0개</p>
<p class="m">a = 4 (2가 둘) : b가 짝수 → b = 2, 4, 6 → 3개</p>
<p class="m">a = 5 (2가 없음) : 0개</p>
<p class="m">a = 6 (2가 하나) : b가 4의 배수 → b = 4 → 1개</p>
<p class="m">n(Q) = 1 + 3 + 1 = 5</p>

<p><span class="step">④ 겹치는 경우를 센다.</span>
<span class="m">a ≤ 3</span>이면서 <span class="m">ab</span>가 <span class="m">8</span>의 배수인 것은
③에서 <span class="m">a = 2, b = 4</span> 하나뿐이다.</p>
<p class="m">n(P ∩ Q) = 1</p>

<p><span class="step">⑤ 확률을 계산한다.</span></p>
<p class="m">n(P ∪ Q) = 18 + 5 − 1 = 22</p>
<p class="m">22/36 = 11/18</p>
<p class="m">답 ②</p>

## 함정

a=6일 때 6b가 8의 배수이려면 4|3b, 즉 4|b → b=4만. b=2는 12라서 안 된다.

## 노하우

<b>P(A∪B) = P(A)+P(B)−P(A∩B)의 실수는 언제나 마지막 항에서 난다.</b> 배수 조건은 소인수로 쪼개 <span class='m'>2<sup>3</sup>|ab</span>처럼 보면 누락이 사라진다.
