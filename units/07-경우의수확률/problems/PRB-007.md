## 문제

<p>집합 <span class="m">X = {1, 2, 3, 4, 5}</span>에 대하여 다음 조건을 만족시키는 함수 <span class="m">f : X → X</span>의 개수를 구하시오.</p>
<span class="cond m">(가) f(1)f(5) = 5</span>
<span class="cond m">(나) Σ<sub>k=1</sub><sup>4</sup> |f(k+1) − f(k)| = 4</span>

## 발상

<span class="m">a<sub>k</sub> = f(k+1) − f(k)</span>로 두면 <b><span class="m">Σa<sub>k</sub></span>는 망원합이라 <span class="m">f(5) − f(1)</span>로 끝점만 남고</b>, 조건 (나)는 <span class="m">Σ|a<sub>k</sub>|</span>를 준다. <b>두 값의 크기가 같아지는 순간 함수는 단조가 된다.</b>

## 풀이

<p><span class="step">① 조건 (가).</span> <span class="m">f(1), f(5) ∈ X</span>이고 곱이 5(소수)이므로</p>
<p class="m">(f(1), f(5)) = (1, 5) 또는 (5, 1)</p>

<p><span class="step">② 망원합.</span> <span class="m">a<sub>k</sub> = f(k+1) − f(k)</span>라 하면</p>
<p class="m">a<sub>1</sub> + a<sub>2</sub> + a<sub>3</sub> + a<sub>4</sub> = f(5) − f(1)</p>

<p><span class="step">③ (f(1), f(5)) = (1, 5)인 경우.</span> <span class="m">Σa<sub>k</sub> = 4</span>이고 <span class="m">Σ|a<sub>k</sub>| = 4</span>. 항상 <span class="m">a<sub>k</sub> ≤ |a<sub>k</sub>|</span>이므로 <span class="m">Σa<sub>k</sub> ≤ Σ|a<sub>k</sub>|</span>인데 양변이 모두 4로 <b>등호</b>다. 합에서 등호가 성립하려면 <b>각 항에서 등호</b>가 성립해야 하므로</p>
<p class="m">a<sub>k</sub> = |a<sub>k</sub>| → a<sub>k</sub> ≥ 0 → f(1) ≤ f(2) ≤ f(3) ≤ f(4) ≤ f(5)</p>
<p>양 끝이 1과 5로 고정이므로 <span class="m">f(2) ≤ f(3) ≤ f(4)</span>를 <span class="m">X</span>에서 고르는 중복조합:</p>
<p class="m"><sub>5</sub>H<sub>3</sub> = <sub>7</sub>C<sub>3</sub> = 35</p>

<p><span class="step">④ (f(1), f(5)) = (5, 1)인 경우.</span> 이번엔 <span class="m">Σa<sub>k</sub> = −4</span>, <span class="m">Σ|a<sub>k</sub>| = 4</span>. 항상 <span class="m">a<sub>k</sub> ≥ −|a<sub>k</sub>|</span>이므로 <span class="m">Σa<sub>k</sub> ≥ −Σ|a<sub>k</sub>|</span>인데 양변이 모두 −4로 <b>등호</b>. 따라서</p>
<p class="m">a<sub>k</sub> = −|a<sub>k</sub>| → a<sub>k</sub> ≤ 0 → f(1) ≥ f(2) ≥ f(3) ≥ f(4) ≥ f(5)</p>
<p class="m"><sub>5</sub>H<sub>3</sub> = 35</p>

<p><span class="step">⑤</span> <span class="m">35 + 35 = 70</span></p>

## 함정

<b>부등호가 왜 뒤집히는가 — 여기서 막힌다.</b> <span class="m">|a|</span>는 <b>양쪽을 다 막는 울타리</b>다.

<p class="m">−|a| ≤ a ≤ |a|</p>

<p><span class="m">(1, 5)</span>인 경우 합이 <b>위쪽 울타리</b> <span class="m">+4</span>에 닿았으니 모든 항이 위쪽에 붙어야 하고(<span class="m">a<sub>k</sub> ≥ 0</span>), <span class="m">(5, 1)</span>인 경우 합이 <b>아래쪽 울타리</b> <span class="m">−4</span>에 닿았으니 모든 항이 아래쪽에 붙어야 한다(<span class="m">a<sub>k</sub> ≤ 0</span>). <b>부등호가 바뀐 것이 아니라, 닿은 울타리가 반대쪽인 것</b>이다.</p>

## 다른 풀이

<p><span class="step">두 경우를 한 번에 — 삼각부등식.</span> ③④를 따로 쓰지 말고 절댓값을 씌워 한 문장으로 만든다.</p>

<p class="m">|a<sub>1</sub> + a<sub>2</sub> + a<sub>3</sub> + a<sub>4</sub>| ≤ |a<sub>1</sub>| + |a<sub>2</sub>| + |a<sub>3</sub>| + |a<sub>4</sub>|</p>

<p><b>등호는 모든 <span class="m">a<sub>k</sub></span>의 부호가 같을 때(0 포함) 성립한다.</b> 이 문제에서는 두 경우 모두</p>
<p class="m">|Σa<sub>k</sub>| = |±4| = 4 = Σ|a<sub>k</sub>|</p>
<p>이므로 곧바로 "모든 <span class="m">a<sub>k</sub></span>의 부호가 같다", 즉 <b>f는 단조함수</b>가 나온다. 부호는 <span class="m">Σa<sub>k</sub></span>가 양수냐 음수냐로 정해진다. 경우를 나눌 필요도, 부등호 방향을 고민할 필요도 없다.</p>

<p><span class="step">걸음으로 읽기.</span> <span class="m">a<sub>k</sub></span>는 <b>방향이 있는 한 걸음</b>, <span class="m">|a<sub>k</sub>|</span>는 <b>그 걸음의 거리</b>다. 그러면</p>
<p class="m">Σ|a<sub>k</sub>| = 총 이동 거리, &nbsp; |Σa<sub>k</sub>| = 출발점에서 도착점까지의 거리</p>
<p>5에서 출발해 1까지 <b>왼쪽으로 4</b>를 가야 하는데 <b>총 이동 거리도 4뿐</b>이다. 오른쪽으로 한 칸이라도 갔다면 되돌아오는 데 2가 더 들어 4를 넘는다. 그러니 <b>한 번도 방향을 바꾸지 않았다.</b></p>

## 노하우

<b>Σ|a<sub>k</sub>| = |Σa<sub>k</sub>| ⟺ 모든 a<sub>k</sub>의 부호가 같다 ⟺ 함수가 단조다.</b> 계차의 절댓값 합이 나오면 먼저 <b>망원합으로 끝점만 남기고</b>, 그 값과 절댓값 합을 견줘 본다. 두 값이 같으면 단조가 강제되고, 남는 일은 <b>중복조합</b>뿐이다. 덧붙여 <b>Σ|a<sub>k</sub>| − |Σa<sub>k</sub>| = 2 × (되돌아간 거리)이므로 언제나 짝수</b>다. 이 홀짝만으로 불가능한 경우를 즉시 걸러낼 수 있다.
