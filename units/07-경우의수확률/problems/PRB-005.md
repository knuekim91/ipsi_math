## 문제

<p>문자 A가 적힌 3장의 카드와 문자 B가 적힌 3장의 카드가 1번째 자리에서부터 차례로 A, A, A, B, B, B가 보이도록 놓여 있다. 이 6장의 카드와 한 개의 주사위를 사용하여 다음 시행을 한다.</p><span class="cond">주사위를 한 번 던져 나온 눈의 수가 <span class="m">k</span>일 때, <span class="m">k ≤ 5</span>이면 <span class="m">k</span>번째 자리의 카드와 <span class="m">(k+1)</span>번째 자리의 카드를 서로 바꾸어 놓고, <span class="m">k = 6</span>이면 6장의 카드를 그대로 둔다.</span><p>이 시행을 4번 반복한 후 6장의 카드가 1번째 자리에서부터 차례로 A, A, A, B, B, B가 보이도록 놓여 있을 때, 3번째 시행에서 나온 눈의 수가 6일 확률은?</p><div class="choices"><span>① 71/373</span><span>② 69/373</span><span>③ 73/371</span><span>④ 71/371</span><span>⑤ 69/371</span></div>

## 발상

나열하지 말고 <b>도달 가능한 배열이 몇 개인지</b> 본다. 4번의 시행으로는 거리 2 이내의 상태에만 갈 수 있어 관리할 상태는 <b>네 개</b>뿐이다.

## 풀이

<p><span class="step">① 전이.</span> <span class="m">S<sub>0</sub></span> = AAABBB에서 k=1,2(A,A), k=4,5(B,B), k=6은 <b>변화 없음</b>. k=3만 배열을 바꾼다. → <span class="m">S<sub>0</sub>→S<sub>0</sub>: 5, S<sub>0</sub>→S<sub>1</sub>: 1</span></p><p><span class="step">②</span> <span class="m">S<sub>1</sub></span> = AABABB에서 <span class="m">S<sub>1</sub>→S<sub>1</sub>: 3, →S<sub>0</sub>: 1, →S<sub>2</sub>: 1, →S<sub>3</sub>: 1</span></p><p><span class="step">③ 2회 후.</span> <span class="m">S<sub>0</sub>: 26, S<sub>1</sub>: 8, S<sub>2</sub>: 1, S<sub>3</sub>: 1</span></p><p><span class="step">④ 남은 2회로 복귀.</span> <span class="m">S<sub>0</sub>: 26, S<sub>1</sub>: 8, S<sub>2</sub>: 1, S<sub>3</sub>: 1</span></p><p><span class="step">⑤ 분모.</span> <span class="m">26·26 + 8·8 + 1 + 1 = 742</span></p><p><span class="step">⑥ 분자.</span> 3번째가 6이면 상태 유지 → 4번째 한 번에 복귀해야 한다. <span class="m">26×5 + 8×1 = 138</span></p><p class="m">138/742 = 69/371</p>

## 다른 풀이

<p><span class="step">상태를 쫓지 말고, 배열을 실제로 바꾼 횟수로 나눈다.</span> 같은 문자끼리의 교환과 <span class="m">k=6</span>은 아무 일도 하지 않는다. 그래서 4번 중 <b>실제로 배열을 바꾼 횟수</b>(효과적인 시행)로 경우를 가른다. <span class="m">S<sub>0</sub></span>로 돌아오려면 그 수는 짝수여야 하므로 <b>0회, 2회, 4회</b>뿐이다.</p>

<p class="m">S<sub>0</sub>에서 제자리인 시행 : k = 1,2,4,5,6 → 5가지 (움직이는 것은 k=3 하나)</p>
<p class="m">S<sub>1</sub>에서 제자리인 시행 : k = 1,5,6 → 3가지</p>

<p><span class="step">(i) 효과적 0회.</span> 네 번 모두 <span class="m">S<sub>0</sub></span>에서 제자리.</p>
<p class="m">5<sup>4</sup> = 625</p>

<p><span class="step">(ii) 효과적 2회.</span> <span class="m">i</span>번째에 나가고(k=3) <span class="m">j</span>번째에 돌아온다(k=3). 그 사이 <span class="m">j−i−1</span>번은 <span class="m">S<sub>1</sub></span>에서 제자리(3가지), 바깥 <span class="m">(i−1)+(4−j)</span>번은 <span class="m">S<sub>0</sub></span>에서 제자리(5가지).</p>
<p class="m">Σ<sub>i&lt;j</sub> 5<sup>(i−1)+(4−j)</sup> · 3<sup>j−i−1</sup></p>
<p class="m">(1,2)=25, (1,3)=15, (1,4)=9, (2,3)=25, (2,4)=15, (3,4)=25 → 114</p>

<p><span class="step">(iii) 효과적 4회.</span> 제자리가 한 번도 없이 4번 만에 복귀. 첫 수는 <span class="m">S<sub>0</sub>→S<sub>1</sub></span>로 강제되고, 남은 셋은</p>
<p class="m">S<sub>1</sub>→S<sub>0</sub>→S<sub>1</sub>→S<sub>0</sub>, &nbsp; S<sub>1</sub>→S<sub>2</sub>→S<sub>1</sub>→S<sub>0</sub>, &nbsp; S<sub>1</sub>→S<sub>3</sub>→S<sub>1</sub>→S<sub>0</sub> → 3가지</p>

<p class="m">분모 = 625 + 114 + 3 = 742</p>

<p><span class="step">분자.</span> 3번째가 6이면 그것은 반드시 <b>제자리 시행</b>이다.</p>
<p class="m">(i) 3번째만 6으로 고정, 나머지 셋은 5가지 → 5<sup>3</sup> = 125</p>
<p class="m">(ii) 효과적인 두 번이 1,2,4번째 중 둘 → (1,2): 1×5 = 5, (1,4): 3×1 = 3, (2,4): 5×1 = 5 → 13</p>
<p class="m">(iii) 3번째가 효과적이어야 하므로 0</p>
<p class="m">분자 = 125 + 13 = 138 → 138/742 = 69/371</p>

<p><b><span class="m">S<sub>2</sub>, S<sub>3</sub></span>를 거의 쓰지 않는다</b>는 것이 장점이다. 효과적 4회인 경우에만 잠깐 등장하고 그마저 3가지뿐이다. 또 <b>분모 742의 대부분(625)이 &lsquo;네 번 내내 아무 일도 없었던&rsquo; 경우</b>라는 것이 바로 보인다. 분모는 <span class="m">5<sup>4</sup>=625</span>보다 조금만 큰 수여야 하므로, 742가 아닌 엉뚱한 값이 나오면 즉시 알아챌 수 있다.</p>

## 노하우

<b>시행 횟수가 3~4회인 확률 문제는 상태 전이표로 끝난다.</b> 특히 <b>같은 문자끼리의 교환은 아무 일도 일어나지 않는다</b>는 관찰이 6가지 분기를 2가지로 줄인다. 조건부확률은 같은 표를 <b>분모 → 분자</b> 순으로 두 번 읽는다.
