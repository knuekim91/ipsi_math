# ipsi_math

**2027학년도 수능 대비 · 수학Ⅰ · 수학Ⅱ · 확률과 통계**
목표 시험일 **2026년 11월 19일(목)**

모르는 문제를 가져오면 → 단원에 분류하고 → 핵심 발상을 뽑아 → 같은 수준의 유사문항을 만들어 →
**인쇄용 PDF**로 돌려주는 저장소입니다.

---

## 이 저장소의 구조

```
ipsi_math/
├─ units/                  8개 단원. 모든 문항이 여기에 쌓입니다.
│  ├─ 01-지수로그/problems/EXP-001.md …
│  ├─ 02-삼각함수/  (TRI)
│  ├─ 03-수열/      (SEQ)
│  ├─ 04-극한연속/  (LIM)
│  ├─ 05-미분/      (DIF)
│  ├─ 06-적분/      (INT)
│  ├─ 07-경우의수확률/ (PRB)
│  └─ 08-통계/      (STA)
├─ intake/                 모르는 문제를 처음 넣는 곳 (사진·캡처·텍스트)
├─ sets/                   인쇄할 문항 묶음 목록
├─ dist/                   생성된 PDF (문제지 + 해설지)
├─ log/progress.md         무엇을 틀렸고 무엇을 처방했는지의 기록
├─ build/make_pdf.py       PDF 생성기
├─ build/make_webapp.py    웹앱 생성기
└─ CLAUDE.md               Claude가 따르는 작업 규약
```

각 문항 파일은 **문제 / 발상 / 풀이 / 함정 / 노하우** 다섯 칸으로 되어 있습니다.
GitHub에서 그대로 읽히고, 동시에 PDF의 원본이 됩니다.

## 쓰는 법

### 1. 모르는 문제가 생겼을 때

문제 사진이나 문항을 Claude에게 그대로 주면 됩니다. 그러면

1. 어느 단원인지 분류하고
2. **핵심 발상 한 문장**을 뽑아 문항 파일로 저장하고
3. 같은 발상을 요구하는 **기존 문항을 저장소에서 찾아내고**
4. 같은 난이도의 **유사문항 3~5개를 새로 만들어** (답은 전부 코드로 검증)
5. **문제지 PDF와 해설지 PDF**를 만들어 드립니다.

### 2. 웹앱으로 보기 (나은이용)

**https://claude.ai/code/artifact/35b8893a-424a-4a1d-b756-1ea1fe4cf24e**

폰·태블릿에서 열어 단원별로 문제를 풀고, 문항마다 `알겠음 / 헷갈림 / 모르겠음`을 표시합니다.
맨 위 **검색창**에 주제·문제 내용·출처를 넣으면 바로 찾을 수 있고(예: `로그`, `중복조합`, `모평`),
그 아래 필터가 **출처 한 줄 / 단원 한 줄**로 놓여 있어 한눈에 보입니다.
막힌 지점을 한 줄 메모해두면 그게 다음 세트의 재료가 됩니다.
문항이 늘어나면 아래 명령으로 다시 만들어 같은 주소에 올립니다.

```bash
python build/make_webapp.py
```

앱에서 문항 오른쪽의 **체크 버튼**으로 풀고 싶은 문항을 골라 두었다가, 하단의 **내보내기**를
누르면 문항 번호가 나옵니다. 그 번호를 아래 세트 파일에 붙여 넣고 `make_pdf.py`를 돌리면
인쇄용 문제지·해설지가 만들어집니다.

> 앱 자체에는 파일 내려받기 기능을 넣지 않습니다. 그 기능을 켜면 **링크 공유가 막혀서**
> 나은이가 앱을 열 수 없게 되기 때문입니다.

### 3. PDF 만들기

```bash
python build/make_pdf.py --set sets/2026-09-04_9월모평_고난도6제.txt
```

| 옵션 | 뜻 |
| --- | --- |
| `--set <파일>` | 세트 파일에 적힌 순서대로 |
| `--unit 05-미분` | 단원 전체 |
| `--status wrong` | 틀렸던 문제만 |
| `--ids DIF-004,DIF-005` | 문항 ID 지정 |
| `--space 큼\|보통\|작음` | 문제지의 풀이 공간 크기 |

만들어지는 파일은 두 개입니다.

- `dist/YYYYMMDD_<이름>_문제.pdf` — 문제 + 풀이 공간. 시험지처럼 인쇄해서 풉니다.
- `dist/YYYYMMDD_<이름>_해설.pdf` — 정답표 + 발상 + 풀이 + 노하우. 다 푼 뒤에 봅니다.

의존성은 없습니다. 파이썬 표준 라이브러리와 컴퓨터에 설치된 Chrome(또는 Edge)만 씁니다.

### 4. 복습 세트 뽑기

```bash
python build/make_pdf.py --status wrong --name 9월_오답총정리
python build/make_pdf.py --status review --unit 07-경우의수확률 --name 확률_재점검
```
