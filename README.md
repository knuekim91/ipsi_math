# ipsi_math

**2027학년도 수능 대비 수학** · 목표 시험일 **2026년 11월 19일(목)**

2027학년도 6월·9월 모의평가 전 60문항을 **문제 → 핵심 아이디어 → 풀이와 정답** 순으로 여는
학습 사이트입니다. 문제를 먼저 풀고, 막히면 아이디어만 열어 다시 시도한 뒤,
마지막에 풀이를 봅니다.

## 구조

```
docs/            GitHub Pages 로 서비스되는 정적 사이트
  index.html     화면
  app.css        디자인 — 단원마다 고유한 색을 갖는다
  app.js         검색 · 필터 · 진도 · 질문 만들기
  data.js        생성물 (build/make_site.py 가 만든다)
units/           문항 원본 8개 단원
build/
  make_site.py   units -> docs/data.js
  latex.py       수식 HTML -> LaTeX (KaTeX 731/731 검증)
  make_pdf.py    인쇄용 문제지 · 해설지
  print.css
```

## 만들기

```bash
python build/make_site.py     # 문항을 고치면 다시 실행
python build/make_pdf.py --all --name 전체
```

## 화면에서 되는 것

- **번호순 / 단원별** 두 가지 보기. 수Ⅰ · 수Ⅱ · 확률과 통계로 묶여 있습니다.
- **내용 검색** — 문제 본문, 핵심 아이디어, 노하우, 출처, 태그까지 훑습니다.
- **단원 색** — 8개 단원이 각자의 색을 갖고, 타일·칩·번호 배지에 일관되게 쓰입니다.
- **바로가기 주소** — `#p-21` 은 21번 문항을, `#u-05-미분` 은 미분 단원을 엽니다.
- **반응 기록** — 알겠음 / 헷갈림 / 모르겠음. 헷갈림·모르겠음이면 메모창이 열리고,
  적은 내용을 문제와 함께 한 덩어리로 만들어 전달할 수 있습니다.
