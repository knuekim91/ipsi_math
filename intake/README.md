# intake — 모르는 문제를 넣는 곳

여기에 문제를 넣고 Claude에게 말하면, 단원에 분류되어 `units/` 로 옮겨집니다.

## 넣는 방법

파일 이름은 `YYYY-MM-DD_출처_메모` 형식으로 합니다.

```
2026-09-10_수능특강_미분_접선개수.png
2026-09-12_이감_확통_29번.txt
```

사진이든 텍스트든 상관없습니다. 다음 정보가 함께 있으면 더 정확히 분류됩니다.

- 어디까지 풀었는지 (또는 아예 손을 못 댔는지)
- 틀린 답을 무엇으로 골랐는지
- 시험 중이었다면 몇 분을 썼는지

세 번째 정보가 특히 중요합니다. **못 푼 문제와 시간이 모자란 문제는 처방이 다릅니다.**

처리가 끝난 파일은 `intake/done/` 으로 옮깁니다.
