## 작업 규칙

- 문항을 만들 때 **반드시 이 표와 대조**한다. 어긋나면 내 풀이가 틀린 것이다.
- 계산이 무거운 문항은 파이썬으로 교차검증한다.
- `exam: 2027-수능완성`, ID 는 `<단원접두>-C<번호>`.
  회차가 다르면 번호를 이어서 준다 (1회 → C01~C30, 2회 → C31~C60 …).
- 파일은 `units/<단원>/problems/2027수능완성/` 에 넣는다.
- 그림이 있는 문항은 **SVG 로 그린다.** 말로 설명하지 않는다.

## PDF 텍스트 층 주의

이 PDF의 텍스트 층은 EBS 자체 인코딩이라 **그대로 쓰면 안 된다.**

```
;3!;  = 1/3      ;1ª5; = 2/15      Û = ²      Ý = ⁵
'     = ∪ 와 ∩ 양쪽에 같은 글자가 쓰인다  ← 특히 위험
```

**지면을 이미지로 렌더링해서 눈으로 읽는다.** (`pymupdf` 140dpi 이상)
