## 확인해 둔 풀이 요점

- **4번** 분자를 유리화하면 `(x−2)`가 약분되어 `1/(√(x+7)+3) → 1/6`
- **6번** `cos²(π/2+θ)=sin²θ`, `cos(π+θ)=−cosθ` → `y=−t²−t+5` (`t=cosθ∈[−1,1]`).
  최대 `21/4` (t=−1/2), 최소 `3` (t=1) → `M+m=33/4`
- **7번** 분모→0이므로 `g(1)=−3`, `g′(1)/2=2 → g′(1)=4`.
  `f(1)=10, f′(1)=14` → `h′(1)=14(−3)+10(4)=−2`
- **8번** 첫 조건은 `−sinθ<0`, 곧 **`sinθ>0`**.
  둘째 식은 통분하면 `2/cosθ=3` → `cosθ=2/3` → `sinθ=√5/3`
- **9번** `∫_{−a}^{a}x²f=0`이 모든 a에서 → `f`는 기함수 → `f=px³+qx`.
  `2(p+q)=8`, `6p+2q=4` → `p=−1, q=5` → `f(2)=2`
- **10번** **두 로그 적분이 정확히 상쇄된다.**
  `∫₀²log₃(x+1)dx = ∫₂⁴log₃(x−1)dx` (둘 다 `∫₁³log₃u du`)
  → `S = 8 + ∫₂⁴(−2x+9)dx = 8+6 = 14`
  격자점 `m`: x=0→5개, x=1→5개, x=2→6개, x=3→3개, x=4→1개 = **20**
  → `S+m = 34`. 두 곡선이 만나는 점은 `(2,5)`, 직선은 `y=−2x+9`.
