# 로그인 서버 붙이기 (10분)

이 폴더의 `Code.gs`를 Google Apps Script로 배포하면
나은이와 아버님의 **진도 · 메모 · 추천 강좌가 기기끼리 자동으로 맞춰집니다.**

배포하기 전에도 사이트는 그대로 돌아갑니다. 다만 기록이 그 기기에만 남습니다.

---

## 1. 스크립트 만들기

1. <https://script.google.com> 접속 → **새 프로젝트**
2. 왼쪽 `Code.gs` 내용을 **전부 지우고**, 이 폴더의 `Code.gs`를 **통째로 붙여넣기**
3. 프로젝트 이름을 `ipsi_math`로 바꾸고 저장 (Ctrl+S)

## 2. 초대코드 정하기

아무나 가입하지 못하게 막는 장치입니다.

1. 왼쪽 톱니바퀴 **프로젝트 설정**
2. 맨 아래 **스크립트 속성** → **속성 추가**
3. 속성 `INVITE_CODE`, 값은 아무 문자열 (예: `naeun-2027-suneung`)
4. **스크립트 속성 저장**

이 코드를 아는 사람만 가입할 수 있습니다. 나은이에게만 알려 주세요.

## 2-1. 시트 미리 만들기 (권장)

편집기 위쪽 함수 목록에서 **`setup`** 을 고르고 **실행**을 누릅니다.

- 권한 승인 창이 뜹니다. 승인하세요. (배포할 때 할 일을 미리 하는 것뿐입니다)
- 아래 **실행 로그**에 데이터 시트 주소와 초대코드가 찍힙니다.
- 내 드라이브에 **`ipsi_math 데이터`** 스프레드시트가 생깁니다.

이 단계를 건너뛰어도 첫 가입 때 자동으로 만들어집니다. 다만 그때까지
드라이브에 아무것도 안 보여서 잘 됐는지 알기 어렵습니다.

### 이미 쓰는 시트에 넣고 싶다면

**스크립트 속성**에 `SHEET_ID` 를 추가하고 그 시트의 ID를 넣으면 됩니다.
ID는 시트 주소의 가운데 토막입니다.

```
https://docs.google.com/spreadsheets/d/  1AbCdEf...XyZ  /edit
                                         └──── 이 부분 ────┘
```

넣지 않으면 스크립트가 알아서 새로 만듭니다.

## 3. 배포하기

1. 오른쪽 위 **배포** → **새 배포**
2. 톱니바퀴 → **웹 앱**
3. 설정 — **이 두 가지가 핵심입니다**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인
   (「이 앱은 확인되지 않았습니다」가 뜨면 **고급** → **ipsi_math(안전하지 않음)로 이동**.
   본인이 만든 스크립트라 정상입니다.)
5. 나온 **웹 앱 URL**을 복사 — `.../exec`로 끝납니다

## 4. 주소 알려 주기

복사한 주소를 Claude에게 주시면 `docs/config.js`에 넣고 배포합니다.
직접 하시려면 `docs/config.js`를 이렇게 고치고 커밋·푸시하면 됩니다.

```js
window.IPSI_API = "https://script.google.com/macros/s/AKfy.../exec";
```

## 5. 첫 가입

사이트에서 **로그인 → 처음이에요(회원가입)**.

- **맨 처음 가입한 사람이 관리자(admin)** 가 됩니다. 아버님이 먼저 가입하세요.
- 그 다음 나은이가 같은 초대코드로 가입하면 됩니다.

---

## 저장되는 곳

배포하면 Google 드라이브에 **`ipsi_math 데이터`** 라는 스프레드시트가 자동으로 생깁니다.
아버님 계정의 개인 파일이고 시트는 세 장입니다.

| 시트 | 내용 |
|---|---|
| `users` | 아이디, 이름, 소금값, 해시, 권한 |
| `state` | 사용자별 진도 전체 (JSON 한 칸) |
| `tokens` | 로그인 유지용 토큰 (60일) |

## 알아 두실 것

- **비밀번호는 그대로 저장되지 않습니다.** 임의의 소금값을 붙여
  SHA-256으로 1000번 돌린 값만 남습니다. 시트를 열어도 비밀번호는 알 수 없습니다.
  다만 은행 수준은 아니니 **다른 곳에서 쓰는 비밀번호는 피해 주세요.**
- **기기가 바뀌어도 로그인하면 그대로 이어집니다.** 같은 문항을 두 기기에서 고쳤으면
  **나중에 고친 쪽**이 남습니다.
- **한 기기에서 계정을 바꾸면**, 앞사람의 기록은 뒷사람 계정으로 넘어가지 않습니다.
  (앞사람 기록은 서버에 그대로 있으니 다시 로그인하면 돌아옵니다.)
- **서버가 멈춰도 사이트는 그대로 쓸 수 있습니다.** 기록은 기기에 남고,
  연결이 돌아오면 자동으로 올라갑니다. 헤더에 `연결 안 됨`으로 표시됩니다.
- 나중에 `Code.gs`를 고치면 **배포 → 배포 관리 → 연필 → 버전 새로 만들기**를 해야
  실제로 반영됩니다. 주소는 그대로입니다.
